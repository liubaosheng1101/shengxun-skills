## 口径与告警

- 节降：基线 11.68（来源：现合同价）→ 最优 10.88；每单位省 0.80，降幅 6.85%
- 节降口径纪律：基线来源必须声明（上次成交价/现合同价/预算价/行情基线）；硬节降、成本规避、现金流改善、一次性费用**不得混报**
- 口径告警：含税/未税口径不一致：部分家报含税、部分家报未税 —— 已按各自的税口径归一，请复核税率是否填对
- 口径告警：运费口径不一致：部分家含运费、部分家未计入 —— 未计入的到厂成本会被低估
- 对账：报价 3 条，其中给出年度口径的 3 条，剔除 0 条（剔除行不静默丢弃，一律登记在告警里）
- 排名（按到厂单位成本）：深科 → 沪连 → 苏恒
