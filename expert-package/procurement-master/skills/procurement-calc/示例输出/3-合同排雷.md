# 合同风险排查结果

> 命中 5 条风险条款（高风险 5 条），另有 5 项关键条款缺失

| 等级 | 风险条款 | 命中措辞 | 风险原因 | 修改方向 |
|---|---|---|---|---|
| 高 | 签收即视为合格 | 签收、即视为 | 签收时无法完成内在质量检验，直接视为合格剥夺异议权。 | 改为「外观、数量当场清点；内在质量以化验/使用验收为准，异议期内可提出」。 |
| 高 | 未约定检验期 | 即视为验收合格 | 未约定检验期，质量问题举证困难。 | 约定到货检验期与书面质量异议期（如 7 日/30 日）；异议期内未验收不视为放弃权利。 |
| 高 | 逾期免责 / 无交期约束 | 发货、不承担 | 供方逾期无成本，交期无保障。 | 增加逾期交货违约金条款及解约权（如 0.05%/日，超 X 天可解约并索赔）。 |
| 高 | 不可抗力被滥用 | 缺货、不承担 | 商业风险（缺货/涨价）不属于法定不可抗力，等于免除供方基本供货责任。 | 删除该约定；改为通过安全库存、备选供应商、价格调整公式分配市场风险。 |
| 高 | 供方单方调价 | 单方调整价格、如有调整另行通知、供方 | 锁量不锁价，预算完全失控。 | 删除单方调价权；如需调价，约定双方书面确认 + 客观指数公式（如挂钩基准价变动幅度）与上限。 |

## 口径与告警

- 排查条款数：16；命中 5 条（高风险 5 条）
- 应有而未见的条款（需人工确认合同里到底有没有）：
- 质量标准：没有质量标准 = 交付物可比性缺失，验收也无标可依
- 质保条款：没有质保 = 质保期内故障无法索赔
- 发票条款：没有发票条款 = 税口径与抵扣时点都可能扯皮
- 交货期：没有交货期 = 无法计算逾期、无法启动违约金
- 不可抗力：没有不可抗力 = 突发事件责任不清；但也要防止被滥用为商业风险的挡箭牌
- 告警：有 5 项应有条款未在文本中出现：质量标准、质保条款、发票条款、交货期、不可抗力
- 告警：若合同确实没有这些条款，签署前应要求补充 —— 「缺失」比「写错」更隐蔽，但也更难在事后补救
- 免责：本结果为**关键词匹配出的疑点清单**，供人工复核使用，不构成法律意见；命中不等于条款无效，未命中不等于没有风险。法律、关务、质检类问题请交由有资质人员确认。
