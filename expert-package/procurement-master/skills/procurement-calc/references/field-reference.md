# 字段参考（填错最容易出问题的地方）

> 配套 `scripts/cli.py`。**带 ⚠️ 的是实测最容易填错、且填错会导致结论反向的地方。**

## 一、`quote`（比价归一）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `quotes[]` | 数组 | ✅ | 每条一家供应商；一次最多 50 条 |
| `quotes[].supplier` | 文本 | ✅ | 供应商名（只作标识，不出现在算法里） |
| `quotes[].unit_price` | 数 | ✅ | 报价单价。**含税就填含税价，并同时置 `price_includes_tax`** |
| ⚠️ `price_includes_tax` | 布尔 | 含税必填 | `true` = 含税价；**不写按"未税价"处理**。填错 → 净单价差一个税率 |
| ⚠️ `tax_rate` | 数 | 含税必填 | `0.13` 与 `13` 都当 13%（≤1 视为小数、>1 视为百分数）。**含税却不给税率 → 直接报错**（不猜） |
| `tax_deductible` | 布尔 | 否 | 进项能否抵扣，默认 `true`。填 `false` → 税额进成本，且会给告警 |
| `qty_per_batch` | 数 | 有运费时必填 | 每批数量，用来摊运费；也可写 `qty` |
| `freight_total` | 数 | 否 | **该批次**的运费总额（不是单价） |
| `annual_demand` | 数 | 否 | 年需求量。不给就只算单位口径，**并会告警说给不出年度结论** |
| `baseline_unit_cost` | 数 | 算节降时必填 | 比较基线（单位口径，与 `landed_unit_cost` 同口径） |
| ⚠️ `baseline_source` | 文本 | 算节降时必填 | 基线来源：上次成交价 / 现合同价 / 预算价 / 行情基线。**不声明来源 → 告警** |

**口径提醒**
- 比价排序看 `landed_unit_cost`（到厂单位成本），**不是** `unit_price`。
- 年度口径叫「年度总获取成本」，**只含发票价 + 运费的结果不叫 TCO**，别对外说成 TCO。
- 混报（有的含税有的未税）**不会报错**，会给告警 —— 告警必须转达用户。

## 二、`score`（供应商评分）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `gates_required[]` | 文本数组 | 是 | 强制资质键名，如 `business_license` / `hazmat` / `iso9001` |
| ⚠️ `suppliers[].gates` | 对象 | 是 | 每个门槛键三态：`true` 通过 / `false` **淘汰** / **不写 = 待核实**（≠通过，也≠淘汰） |
| `criteria[].key` | 文本 | ✅ | 指标键，要和 `metrics` 里的键一致 |
| `criteria[].weight` | 数 | ✅ | **合计必须等于 1**，否则报错（不自动凑） |
| `criteria[].direction` | 文本 | ✅ | `cost` = 越低越好；`benefit` = 越高越好 |
| `suppliers[].metrics` | 对象 | 是 | 指标值；**缺某个指标 → 该指标权重从分母剔除**（不当 0 分），并给告警 |

**口径提醒**
- 门槛淘汰的供应商**不进入排名**，但表里仍会列出它的分数（便于说明差距）——呈现时说清"已淘汰"。
- 只有 2 家候选时会告警建议改阈值锚定法：min-max 在两家时极易失真。
- 所有候选某指标值相同（max = min）→ 给 0.5 中性分，不会崩。

## 三、`contract`（合同排雷）

输入不是 JSON，是**合同纯文本**（可只贴关键条款）：

```
python scripts/cli.py contract --in 合同.txt --format md
```

- 命中 16 类高风险条款中的哪几条，每条给「风险原因 + 修改方向」
- 另有 8 项**应有而未见**的条款检查（验收/质保/违约/发票/交货期/管辖/不可抗力/质量标准）
- ⚠️ 结果是**疑点清单，不是法律意见**。命中 ≠ 条款无效；未命中 ≠ 没问题（可能换了说法）。
- 组合规则覆盖"换词写法"：如「原材料上涨 + 不承担」会命中"不可抗力被滥用"，
  但**只承认组内 OR、组间 AND 的同时命中**，单个词不会误报。

## 四、`ledger`（台账行）

| 字段 | 必填 | 说明 |
|---|---|---|
| `kind` | ✅ | `invoice` / `request` / `quote`（也可用 `--doc-kind` 传） |
| `date` `doc_no` `supplier` `material` | ✅ | 缺了会进 `missing` 清单 |
| `qty` `unit_price` | ✅ | 金额 = 数量 × 单价 |
| ⚠️ `tax_rate` | 有税必填 | 缺了 → 只给金额并标"税口径待核实"，**不按 0 税硬算** |
| ⚠️ `price_includes_tax` | 有税必填 | 未声明 → 明说"暂按未税处理，请核原件"，**不默认一种口径** |

导出列顺序固定为：`kind,date,doc_no,supplier,material,spec,qty,unit,unit_price,tax_rate,amount_net,amount_gross,tax_basis_note`

## 五、`fields`（询价字段库）

```
python scripts/cli.py fields --category 化工液体原料
```

已知品类：化工液体原料 / 化工固体原料 / 阀门 / 法兰与紧固件 / 电气与仪表 / 劳保与 MRO。
不认识品类不会静默返回空，而是**显式提示**并列出已知品类。

**通用 10 字段**（每单都要问）：规格型号 · 数量 · MOQ · 含税口径 · 交货地 · 运费归属 ·
账期 · 报价有效期 · 退换/质量异议期 · 资质要求。

> 少问一项，报回来的价就不可比，比价时要返工 —— 这是最常见的返工原因。

## 六、通用

- 数字可以写成字符串（`"12.50"`）或数值（`12.5`）；金额一律按 Decimal 算到分。
- JSON 文件建议存 UTF-8；带 BOM 也能读（记事本另存会产生 BOM）。
- `--demo` 用内置示例跑一遍，**不需要准备任何数据** —— 第一次用建议先跑它。
