# KB1 · 方法论与计算口径（一期：询价/比价/评分）

本库只含 WF1/WF2/WF3 使用的 TRACE 方法论、归一化口径与计算公式。
库存、landed、price 趋势模式一期不收录。每个 `##` 条目为一个独立分块。

## TRACE 五步骤
- T 定决策：一句话锁定批准什么动作、规格/SLA、数量与周期口径、预算硬约束、
  比较基线、审批规则。拒绝"找个最好的供应商"这类模糊目标。
- R 对齐口径：比较前归一化供应商主体、物料规格等效性、单位包装、数量阶梯、
  币种汇率、含税/税率/发票类型/可抵扣性、贸易术语与费用边界、交货地、
  报价有效期、缺失值与剔除行。
- A 算经济账：按"纸面报价 → 净单价 → 到厂/可用单位成本 → 年度总成本 →
  预算现金流 → 不确定区间"分层，只解释最大的两三个驱动项。
- C 压力测试：合规、交付、产能、连续性、符合性五个透镜；每条问题归入
  门槛项 / 先决条件 / 加权偏好 / 持续监控之一。重大决策至少压一个最可能
  发生的不利情景。
- E 给行动：每条建议含动作、责任人角色、时机/触发条件、前置闸门、兜底、
  复核指标、停止条件。禁止以"得分第一"结尾。

## 归一化八项口径
1. 供应商法律主体（合同章名称）与交易名称是否同一家。
2. 物料规格、等级、品牌替代是否等效；等效性存疑列为先决条件。
3. 单位与包装（个/箱/托盘）、数量阶梯与 MOQ。
4. 币种、汇率来源与日期。
5. 含税/未税、税率、发票类型（专票/普票）、是否可抵扣。
6. 贸易术语与费用边界（运费、保险、港杂谁承担）。
7. 交货地、报价有效期、付款条件。
8. 缺失值、争议值、暂定价、被剔除行单独登记。

## 含税未税归一公式
比率一律用小数（0.13 = 13%）。
- 含税价且进项可抵扣：净单价 = 含税单价 ÷ (1 + 税率)
- 含税价但不可抵扣：净单价 = 含税单价（税额计入成本）
- 未税价：净单价 = 报价单价
- 反向：含税价 = 未税价 × (1 + 税率)
同一次比价必须全站同一口径，默认一般纳税人视角用不含税净额。

## 运费摊薄公式
- 单位运费 = 运费总额 ÷ 报价数量
- 到厂单位成本 = 净单价 + 单位运费
（若另有起运/入库前费用，同样按数量摊入单位成本。）

## 年度 TCO 公式
- 年批次数 = 年需求量 ÷ 每批数量
- 年度总获取成本 = 年需求量 × 净单价 + 年批次数 × 每批运费
只含发票价加运费的结果不得称为"TCO"；未提供年需求量时只算批次口径。

## 节降额与节降率公式
- 节降额 = (基线单位成本 − 最优方案单位成本) × 口径数量
- 节降率 = (基线单位成本 − 最优方案单位成本) ÷ 基线单位成本
基线必须声明来源：上次成交价 / 现合同价 / 预算价 / 行情调整基线。
节降分类不得混报：硬节降（同口径真降）、成本规避（挡住涨价/减量）、
现金流改善（账期变化）、一次性费用单列。

## 供应商门槛规则
- 门槛项（强制认证、营业执照、环保安全、危化资质、强制准入）不通过即淘汰，
  不得被任何加权高分或低价抵消。
- 证据状态三态：true=通过，false=不通过（淘汰），缺省=待核实（先决条件，
  补证后可批）。

## 加权评分公式
- 效益型（越高越好）：归一化 = (x − 最小) ÷ (最大 − 最小)
- 成本型（越低越好）：归一化 = (最大 − x) ÷ (最大 − 最小)
- 总分 = Σ(权重 × 归一化得分) ÷ Σ(有效权重)
规则：权重合计 = 1；缺失值不当 0 分，该指标权重从分母剔除并重新归一；
max = min 时所有候选给中性分 0.5；候选仅 2 家时 min-max 易失真，
建议改用阈值锚定法人工复核；门槛失败者不进入排名。

## 证据分级五状态
实测（用户原始数据）、查证（外部来源附日期）、推算（按公式算出）、
假设（情景/工作假设）、待核实（决策相关但缺失）。五类必须标注清楚，
不得把空白、0、N/A、未披露当作同义值。

## 计算前对账清单
统计来源/纳入/剔除行数；数量金额合计与原始表核对；检查重复单号；
归一后单位币种一致；报价是否在有效期；负数量负价格异常零值检查；
权重合计与方向检查；异常行登记不得静默丢弃。报告须写明分母口径
（剔除后按多少行、多少金额在算）。

## 数值精度原则
数值精度与数据质量匹配：报价给到分，结果不报到厘以下；避免虚假精度。
合计数与原始表对账，披露剔除行和口径变化。
