# 谈判策略框架（按类型分块）

## 涨价应对
1. 要书面依据：涨价对应的原料/指数及涨幅证据。
2. 拆分诉求：只接受可证实的成本推动部分，拒绝普涨。
3. 交换条件：锁量、延长账期、预付款、年度框架换价格不变。
4. 备选施压：同步引入二供报价，给切换时间表。
5. 兜底：接受部分涨幅但设上限与复评节点。

## 新品压价
1. 先做 should-cost：拆解材料/人工/费用，锚定合理区间。
2. 用批量与后续合作换首单优惠。
3. 要求费用透明：模具费/运费/包装费单列，防止隐性加价。
4. 留二供份额保持竞争压力。

## 账期谈判
1. 用更大份额/更长期合作换账期延长。
2. 账期与价格联动报价（现汇价 vs 账期价），比较资金成本。
3. 可接受票据（银承）替代拉长账期。

## 年度降本
1. 用全年量打包招标，多供应商竞价。
2. 组合拳：降价+年返+免运费+缩短交期，分项计功。
3. 对战略供应商谈 VMI/联合降本，节余分成。
4. 设阶梯目标与季度复盘，结果写入合同补充协议。

## 犯错索赔
1. 先固定证据：质检单、照片、批次、损失明细。
2. 诉求分层：直接损失必赔，间接损失协商。
3. 方式可选：货款抵扣/补货/质量保证金，降低对方抵触。
4. 复盘改进：要求 8D/纠正预防措施，防止再犯。
