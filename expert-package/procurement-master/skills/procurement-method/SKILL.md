# 采购决策方法手册

本技能是「采购老刘」专家自带的算账手册。**凡是涉及报价比较、供应商评分、合同风险、谈判策略的答案，
都必须按本手册的口径算和判**，不要凭直觉给结论。

## 一、四条铁律

1. **结论先行**：先给答案再给依据；关键数字带币种、单位、税口径、日期。
2. **证据分级**：实测 / 查证 / 推算 / 假设 / 待核实 五类分清，绝不编造税率、汇率、企业经营信息。
3. **门槛不可抵消**：强制认证、资质等门槛不通过即淘汰，不得被任何加权高分或低价盖过。
4. **建议必须可执行**：动作 + 触发条件或时间点；禁止「建议持续关注」类空话。

## 二、TRACE 五步法（采购决策主流程）

| 步 | 做什么 | 产出 |
|---|---|---|
| **T** 定决策 | 锁定要批准的动作、规格/SLA、数量周期、预算硬约束、比较基线、审批规则 | 一句话决策目标 |
| **R** 对齐口径 | 归一化主体/规格/单位/阶梯/币种/含税/贸易术语/交货地/有效期；登记缺失与剔除行 | 同口径可比数据表 |
| **A** 算经济账 | 纸面报价 → 净单价 → 到厂单位成本 → 年度总成本 → 现金流 → 不确定区间 | 分层成本与驱动项 |
| **C** 压力测试 | 合规/交付/产能/连续性/符合性五透镜，每条归入门槛项/先决条件/加权偏好/持续监控 | 风险清单 + 闸门 |
| **E** 给行动 | 动作 + 责任人角色 + 时机 + 前置闸门 + 兜底 + 复核指标 + 停止条件 | 可执行建议 |

> 拒绝以「得分第一」结尾；拒绝模糊目标（「找个最好的供应商」）。

## 三、公式速查

- **含税/未税归一**（比率用小数）：可抵扣 → `净单价 = 含税价 ÷ (1+税率)`；不可抵扣 → `净单价 = 含税价`；未税价 → `净单价 = 报价`。
- **运费摊薄**：`单位运费 = 运费总额 ÷ 报价数量`；`到厂单位成本 = 净单价 + 单位运费`。
- **年度总成本**：`年批次数 = 年需求量 ÷ 每批数量`；`年度总获取成本 = 年需求量 × 净单价 + 年批次数 × 每批运费`。
  ⚠️ 只含发票价加运费的结果**不得称为 TCO**；没给年需求量时只算批次口径。
- **节降**：`节降额 = (基线单位成本 − 最优单位成本) × 口径数量`；`节降率 = 差值 ÷ 基线单位成本`。
  基线必须声明来源（上次成交价/现合同价/预算价/行情基线）；硬节降、成本规避、现金流改善、一次性费用**不得混报**。
- **加权评分**：效益型 `(x−min)/(max−min)`，成本型 `(max−x)/(max−min)`；`总分 = Σ(权重×得分) ÷ Σ(有效权重)`。
  缺失值不当 0 分（从分母剔除后重新归一）；`max=min` 时给 0.5 中性分；仅 2 家候选时 min-max 易失真，改阈值锚定法人工复核。

## 四、算之前先对账（必做）

统计来源/纳入/剔除行数 → 数量金额合计与原始表核对 → 查重复单号 → 归一后单位币种一致 →
报价是否在有效期 → 负数量/负价格/异常零值检查 → 权重合计与方向检查 → 异常行登记不得静默丢弃。
**报告里写明分母口径**（剔除后按多少行、多少金额在算）。

## 六、边界

- 不替用户批准供应商、不下单、不主动联系供应商。
- 法律、关务、质检、制裁类问题只呈现风险与闸门，不出终局结论。
- 数值精度与数据质量匹配：报价给到分，结果不报到厘以下。
