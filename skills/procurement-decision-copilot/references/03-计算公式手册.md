# 03 · 计算公式手册

计算前先声明商业口径。比率一律用小数（0.13 表示 13%）。以下公式与 `scripts/procurement_calc.py` 五个模式一一对应；决策关键数字必须由脚本或透明代入公式产生。

## 一、报价与总获取成本（quote）

### 1. 含税/未税归一

```
若报价含税且进项可抵扣：净单价 = 含税单价 ÷ (1 + 税率)
若报价含税但不可抵扣：  净单价 = 含税单价（税额进成本）
若报价未税：          净单价 = 报价单价
```

### 2. 本次报价批次总获取成本

```
批次总获取成本 = 报价数量 × 净单价
               + 运费 + 起运/入库前费用 + 目的地费用
               + 一次性费用（开模/打样/实施/切换）
               + 年度服务费/售后费
               − 返利
单位获取成本 = 批次总获取成本 ÷ 报价数量
```

### 3. 年度口径 TCO（给了年需求量时）

```
年批次数 = 年需求量 ÷ 每批数量
年度总获取成本 = 年需求量 × 净单价
               + 年批次数 × 每批运费及杂费
               + 年度服务费
               + 首年一次性费用
               − 年度返利
```

合同最低消费承诺（minimum spend）、已承诺未使用的产能要单独列示，不能藏进均价。只含发票价加运费的，不许叫"TCO"。

### 4. 节降额与节降率

```
节降额 = (基线净单价 − 本方案单位获取成本) × 口径数量
节降率 = 节降额 ÷ 基线口径总成本
```

基线必须声明：上次成交价 / 现合同价 / 预算价 / 行情调整基线。节降分四类，不得混报：

- **硬节降**：同口径单价真的降了
- **成本规避**：挡住了涨价或减少了用量
- **现金流改善**：账期/付款节奏变化，成本未必降
- **一次性费用**：开模、切换费单列

## 二、价格分析（price）

### 1. 数量加权均价 WAP

```
WAP = Σ(数量ᵢ × 可比单价ᵢ) ÷ Σ(数量ᵢ)
```

只纳入正数、有效、未取消的行；权重默认按采购数量，不做无权重的供应商简单平均。

### 2. 采购价格差异 PPV

```
PPV = (实际单价 − 基线单价) × 实际数量
```

正负号口径全表统一，用"有利/不利"表达而不是只看正负。

### 3. 价格指数与波动

```
价格指数ₜ = WAPₜ ÷ WAP基期 × 100
变异系数 CV = 标准差(价格) ÷ 均值(价格)
```

规格、地点、币种必须一致，不一致要做结构调整后再比。离群值多的数据同时报中位数与中位数绝对偏差（MAD）。

### 4. 价差桥（解释钱差在哪）

把单价或支出变化拆成：供应商自身调价、供应商结构变化、规格/等级变化、地点/运费变化、汇率/税率变化、未解释残差。**残差不得归功于谈判。**

### 5. 行情调整后差异

```
行情调整差异 = 实际价格变化 − 可比基准变化
```

基准要对齐滞后周期、等级、区域、单位、币种；历史联动关系经核实后，基准才可作为证据。

## 三、供应商绩效与评分（score）

### 1. 交付与质量

```
OTD 准时交付率 = 准时交付行数 ÷ 应交付行数
OTIF 准时足量率 = 准时且足量交付行数 ÷ 应交付行数
批次合格率 = 合格批次 ÷ 检验批次
退货率 = 退货数量 ÷ 实收数量
PPM = 不良数 ÷ 检验数 × 1,000,000
```

容差窗口、日期口径（要货日/确认日/发货日）、检验覆盖与不良定义不同的 PPM 不可互相比。

### 2. 产能余量

```
产能余量 = 瓶颈工序已验证产能 − 本项目需求产能
余量率 = 产能余量 ÷ 本项目需求产能
```

用瓶颈工序的**已验证**产能，不用铭牌产能。

### 3. 加权评分（门槛通过后才进入）

```
总分 = Σ(权重ⱼ × 归一化得分ⱼ) ÷ Σ(有效权重ⱼ)
```

效益型指标（越高越好，如合格率）：`归一化 = (x − 最小) ÷ (最大 − 最小)`
成本型指标（越低越好，如价格）：`归一化 = (最大 − x) ÷ (最大 − 最小)`

规则：

- 权重合计 = 1；每个指标标明方向、量纲变换、缺失处理；
- **缺失值不得当 0 分**：该指标权重从分母剔除并重新归一，同时在结果中告警；
- max = min 时该指标所有候选给中性分 0.5 并告警；
- 候选只有 2 家时 min-max 极易失真，优先改用阈值锚定评分（如价格相对预算线的位置）并在报告说明；
- 门槛失败单独列示为"淘汰"，不进入加权排名。

### 4. 集中度

```
供应商份额 = 该供应商采购额 ÷ 口径采购总额
HHI = Σ(各供应商份额²)
```

集中度只是敞口指标，不是风险证据；要叠加切换周期、可替代性、工厂与二级供应商重合度一起看。

## 四、库存与补货（inventory）

```
可用库存 = 账面库存 − 冻结 − 已分配
库存头寸 = 可用库存 + 在途 − 欠货 − 已承诺需求
```

### 1. 安全库存与再订货点

需求波动主导（提前期稳定）：

```
安全库存 = z × 日需求标准差 × √提前期天数
ROP = 日均需求 × 提前期天数 + 安全库存
```

需求与提前期都波动（相互独立）：

```
安全库存 = z × √(提前期均值 × 日需求方差 + 日均需求² × 提前期方差)
ROP = 日均需求 × 提前期均值 + 安全库存
```

常用服务水平 z：90%≈1.28，95%≈1.65，98%≈2.05，99%≈2.33。周期性、间歇式、促销拉动的需求不套正态公式，应用经验分位数或情景模拟。

### 2. 建议下单量

```
原始建议量 = 目标库存头寸 − 当前库存头寸
约束后建议量 = 依次套 MOQ 下限、订货倍数、产能上限、保质期/预算/整柜约束
```

原始量与约束后量都要展示，让用户看见被什么约束放大或截断。≤0 不出单，只给监控提示。

### 3. 覆盖与周转

```
可供货天数 = 可用库存 ÷ 日均需求
库存周转率 = 年销售成本 ÷ 平均库存金额
过剩量 = max(0, 计划期末预计库存 − 期末目标库存)
```

近期需求有季节性或脉冲性时不能只用平均日需求。过剩、呆滞、死库存、冻结、临期库存必须分开，处置动作不同。

## 五、进口物流与税费（landed）

### 1. 完税价格（中国进口一般规则，具体以海关认定为准）

```
CIF 完税价格 = 成交价格 + 运费 + 保险费（按申报口径调整）
关税 = 完税价格 × 关税税率
消费税（从价，涉及时）= (完税价格 + 关税) ÷ (1 − 消费税率) × 消费税率
进口增值税 = (完税价格 + 关税 + 消费税) × 增值税率
```

EXW 成交还要加出口地费用；CFR 加保险；CIF 不重复加运保。完税价格口径、HS 归类、原产地资格、反倾销/反补贴税、协定税率适用条件，全部是**待海关/关务确认的闸门**，脚本只做情景测算。

### 2.  landed unit cost

```
Landed 总成本 = 货值 + 全程运费 + 保险 + 起运地费用 + 目的地港杂 + 报关费
              + 关税 + 不可抵扣的增值税/消费税 + 其他法定税费
Landed 单位成本 = Landed 总成本 ÷ 实际可用收货数量
```

可抵扣增值税不进成本，但在现金流中单列"垫付税款"。

### 3. 集装箱利用率

```
重量利用率 = 货重 ÷ 限重
体积利用率 = 货物体积 ÷ 可用箱容
约束利用率 = 两者取大
```

出柜前要复核尺寸、堆码、危险品隔离、箱底承重、包装限制。

### 4. 线路对比必须同时报

预期 landed 成本、预期门到门天数、有证据支持的 p90/p95 或不利情景成本与时效、班期频次、合规可行性、资金与库存占用。不能只比运费单价。

## 六、敏感性与决策质量

- 对最可能反转结论的变量做盈亏平衡分析：`x 取何值时 A 方案总成本 = B 方案总成本`。
- 情景表只变动真正影响决策的驱动因素，固定口径：基准 / 不利 / 有利 / 闸门失败。
- 报告必须写出**决策稳定性**：结论在哪些假设区间内保持不变。脆弱结论不得藏在平均数后面。
- 数值精度与数据质量匹配：报价给到分，结果不报到厘以下；预测数据给两位小数没有意义。
