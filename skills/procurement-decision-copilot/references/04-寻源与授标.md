# 04 · 寻源与授标

适用于：找供应商、发 RFI/RFP/RFQ、筛短名单、出比价表、决定授标与份额。

## 一、寻源推进顺序

```
界定需求与门槛 → 市场扫描 → 初筛长名单 → RFI 摸底 → RFQ/RFP →
报价归一化 → 门槛校验 → 加权评分 → 情景压测 → 授标/份额 → 合同与试点闸门
```

不要跳过门槛直接比价格；不要在没定义需求前群发 RFQ（拿回来的报价无法归一）。

## 二、需求界定：先分清门槛项与加权项

- **门槛项（不通过即出局）**：法定认证（如 3C、生产许可）、行业准入、环保资质、制裁与出口管制、必备规格、最小产能、必须覆盖的交货地、财务与营业状态。
- **加权项（可权衡）**：净价水平、质量表现、交付可靠性、账期、服务响应、技术能力、配合度。
- 模糊的"质量好、服务优"必须拆成可举证的指标（批次合格率、响应时长、驻场能力），否则不进评分表。

## 三、市场扫描的合规来源

行业协会与认证查询名录、展会展商名单、招投标中标公示、客户/伙伴生态目录、专利与技术资料、合法的进出口数据。搜索排名、广告位、黄页会员等级**不能**作为供应商实力证据。

长名单截止条件：相关市场分层（头部/区域/细分专精）已有代表，新候选人不再改变短名单结构和 RFQ 设计——不要为凑数量无限收集。

## 四、RFx 设计要点

1. RFQ 必须附统一报价表：同规格、同数量阶梯、同贸易术语、同币种、同税率口径、同有效期、同费用包含边界；
2. 要求供应商按"不含税净价 + 税率 + 发票类型 + 是否含运费/包装"分项填报，禁止只给一个含税总价；
3. 明确账期、MOQ、提前期、产能承诺、返利、售后条款的填报格式；
4. RFP（复杂服务/设备）另加：SLA、实施计划、验收标准、付款里程碑、退出与数据归属；
5. 所有供应商给相同信息、相同时限；补答机会一视同仁并留痕。

## 五、归一化比价比什么（用脚本 quote 模式）

1. 同币种、同税率口径下的**净单价**；
2. 含运费、入库前费用、一次性费用摊销的**单位获取成本**；
3. 年需求量口径下的**年度总获取成本**（账期差异用现金流视角另列，必要时按企业资金成本折算）；
4. 报价背后的**商业条件**：MOQ、账期、提前期、产能、有效期、返利触发条件。

只有净价差、忽略一次性费用和账期，是最常见的选错供应商原因。

## 六、评分操作纪律

- 门槛先于评分：脚本 score 模式先输出每家门槛通过/淘汰状态，淘汰原因写具体（缺哪张证、哪条硬指标不满足）。
- 权重在开标/看价前确定并留痕；价格权重不应压倒一切，也不应低到价格失去约束，常见区间 20%–40%，按物料杠杆与风险调整。
- 评分人独立打分、事实型指标（合格率、产能、账期）由数据直接生成，主观指标写明举证要求。
- 缺失数据按 `03-计算公式手册.md` 的规则剔除权重重归一，严禁默认零分或默认满分。

## 七、授标与份额策略

| 策略 | 适用情形 | 注意点 |
|---|---|---|
| 独家授标 | 模具/认证绑定、量小、切换成本高 | 必须评估单点失效，写明双供触发条件 |
| 主供 + 备份（如 70/30） | 有连续性要求的通用物料 | 备份量要足以维持产线学习曲线，过低等于没有备份 |
| 双供对半 | 供给紧张、需求波动大、制衡需要 | 管理成本与价差损失要算进 TCO |
| 试点后再授 | 新供应商或新方案 | 定义试点批量、验收指标、转正式的量化条件 |

授标建议要写明：份额或金额、生效条件、试点期限、价格保护与年度降本条款、产能预留、退出安排。

## 八、授标后必须落地的闸门

- 合同/质量协议/保密协议签署，价格、税率变动调整公式、账期、违约责任写入；
- 首件/小批验收标准与封样；
- 产能与原材料备料承诺核实；
- 关键件二级供应商报备；
- 试点期复核指标（OTD、合格率、价格执行）与转正/退出触发条件。

## 九、红线

供应商选择是**商业建议不是认证背书**；公开榜单只是背景不是可成交价；不得以分析为由暗示已获预算、采购授权或法务批准；禁止使用任何来源不明或非法获取的企业/个人数据。
