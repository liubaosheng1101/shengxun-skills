# 08 · 国际物流与税费

适用于：进口采购 landed cost 测算、货代报价对比、运输方式选择（海/空/铁/卡）、贸易术语比较、关税与合规闸门梳理。

## 一、报价归一化：先确认费用边界

不同货代报价口径差异极大，比较前逐项对照"谁承担"：

- 起运地：提货费、出口报关、产地证、港杂/码头费、文件费、订舱费；
- 主运输：基础运费、燃油附加（BAF/EBS）、旺季附加（PSS）、货币调整（CAF）、塞港/绕航附加、战争险附加；
- 保险：险种（一切险/平安险）、投保加成（常见 CIF×110%）；
- 目的地：换单费、THC、港杂、堆存、提箱、拖车、报关报检、查验费、滞箱滞港（detention/demurrage）；
- 税：关税、进口增值税、消费税（应税消费品）、反倾销/反补贴税、协定税率差异；
- 免堆免箱期、超期费率、班期频次、运输时效、报价有效期、费用不含项。

## 二、贸易术语与费用边界（常见）

| 术语 | 卖方责任到 | 买方承担的主段 |
|---|---|---|
| EXW | 工厂交货 | 全程（提货、出口清关、运保、进口清关） |
| FOB | 货物越过船舷/装上船（出口清关后） | 主运费、保险、进口段 |
| CFR | 成本 + 运费到目的港 | 保险、进口段 |
| CIF | 成本 + 保险 + 运费到目的港 | 进口清关与后段 |
| DAP/DPU/DDP | 分别到目的地/卸货地/完税后交货 | DDP 下卖方承担进口税费 |

术语不决定风险质量，只决定费用与手续边界；DDP 报价要核实卖方进口资质与税费承担条款，国内买家还要注意增值税链条（自己是否拿得到可抵扣凭证）。

## 三、Landed cost 计算（脚本 landed 模式）

```
外币货值 × 汇率 = 人民币货值
完税价格 = 货值 + 运保（按 EXW/FOB/CFR/CIF 口径补项）
关税 = 完税价格 × 关税税率
消费税（涉及时）= (完税价格 + 关税) ÷ (1 − 消费税率) × 消费税率
进口增值税 = (完税价格 + 关税 + 消费税) × 增值税率
Landed = 货值 + 全程运保杂费 + 关税 + 不可抵扣的增值税与消费税 + 其他税费
Landed 单位 = Landed ÷ 实际可用收货数量
```

- 汇率注明来源与日期（默认人民币汇率中间价）；
- 可抵扣增值税不进成本，单列为垫付资金；
- 附加费、查验费等或有费用，只有概率/历史依据充分时才计入期望值，否则列情景。

## 四、必须作为闸门提示的事项（不由技能下结论）

1. **HS 编码归类**：决定税率与监管条件，可能存在多个可归子目，提示以海关认定/预归类决定为准；
2. **原产地与协定税率**：RCEP 等优惠税率需原产地证、直接运输等条件，逐项核对；
3. **贸易救济**：反倾销、反补贴、保障措施税及加征关税，按商品 HS 与原产国核查；
4. **进口准入**：法检、许可证、3C、食品/化妆品/医疗器械等专项准入；
5. **制裁与出口管制**：交易对手、银行、船舶、最终用途筛查；
6. **消费税应税商品**（如部分化妆品、酒类等）的计税口径。

输出统一措辞："税率与归类为按公开口径的情景测算（来源/日期见报告），实际以报关时海关认定与企业税务处理为准。"

## 五、运输方式与线路对比

不止比运费，固定输出七项：

1. 预期 landed 单位成本；
2. 门到门时效（天数区间）；
3. 不利情景成本与时效（甩柜、压港、查验、旺季）；
4. 班期/班次频次与截单时间；
5. 库存与资金占用（慢运输 = 高在途库存，按货物价值×资金成本×在途天数算持有成本）；
6. 合规可行性（监管、限重、危险品、电池/液体等特殊货要求）；
7. 免箱期与超期费规则。

空运成本高但在途库存低、缺货损失大时可能整体更优；海运整柜利用率（重量/体积取大约束，公式见 `03-计算公式手册.md`）决定是否值得整柜 vs 拼箱。

## 六、成本优化的常见抓手

- 贸易术语重谈：EXW 转 FOB 自己控主运输往往更省，但要具备出口段操作能力；
- 拼箱转整柜的盈亏平衡点（货量阈值用两个方案总成本相等计算）；
- 多港/多线路组合与旺季提前发运；
- 包装优化提箱容利用率（改设计前先做装载验证）；
- 账期与税金：增值税可抵扣时的资金占用、保函/保单替代保证金；
- 报价有效期与附加费锁死条款，防止低价揽货后附加费找补。

## 七、红线

- 不编造税率、汇率、附加费标准；环境支持联网就查证并记录来源与日期，不支持就标"待核实"；
- 不对 HS 归类、原产地资格、合规筛查做终局认定；
- 不提供走私、低报价格、伪报品名、违规转口等任何规避监管的建议——这是硬红线，相关请求直接拒绝。
