# 02 · 数据口径与归一化

用户提供的文件格式五花八门。原则：**保留原始列不动，新增归一化字段，每行数据可追溯回来源。**

## 一、来源登记（每组决策级数据都要带）

- 来源名称与类型：报价单 / 采购订单 / 收货记录 / 发票 / 合同 / 预测 / 库存台账 / 绩效卡 / 公开来源
- 数据归属人（谁提供的）、所属期间
- 获取日期、业务生效日期、市场或辖区
- 证据状态：实测 / 查证 / 推算 / 假设 / 待核实
- 处理备注（做了哪些换算或剔除）

保留来源文件的行号或单号，确保归一化后每一行都能回溯。

## 二、国内采购特有的税费归一化（最容易出错）

1. **先确认发票类型与税率**：增值税专用发票（常见 13% 货物、9%、6% 服务、3% 小规模）、普通发票、收据。
2. **再确认能否抵扣**：一般纳税人取得合规专票、用于应税项目时，进项税额可抵扣，**成本用不含税净额**；不能抵扣时（普票、小规模取得专票但用途不可抵、用于免税/集体福利等），**税额计入成本**。
3. 换算：
   - 含税价 → 不含税净额 = 含税价 ÷ (1 + 税率)
   - 不含税价 → 含税价 = 不含税价 × (1 + 税率)
4. 报价比较必须站在同一个口径：要么全用不含税净额（默认，一般纳税人视角），要么全用含税价（现金流/付款视角），并在报告开头声明。
5. 现金流视角单独展示（要付多少钱、什么时候付），不要和成本视角混在一行里。

## 三、其他归一化字段（按需建立，不要一股脑全建）

- 标准供应商 ID / 标准物料 ID
- 原始单位、归一化单位及换算系数（1 箱 = 多少只，换算表要记录系数、生效日期、确认人）
- 原始数量、归一化数量
- 币种、汇率、汇率日期（默认用中国外汇交易中心人民币汇率中间价，注明日期；合同另有约定按合同）
- 贸易术语 + 指定地点（FOB 上海 / EXW 苏州 / DDP 东莞仓）
- 起运地、目的地、交货仓、线路
- 下单/发货/承诺到货/实际到货/发票日期
- 报价有效期起止
- 费用包含边界：运费、保险、关税、港杂、包装、实施、售后、返利各自是否含在报价内

## 四、五类最小表结构

### 1. 供应商报价（对应报价对比模板）

供应商、报价单号、物料名称与规格、数量阶梯、报价单位、币种、报价单价、含税/未税、税率、发票类型、是否可抵扣、贸易术语/交货地、运费、包装费、账期天数、MOQ、提前期（天）、报价有效期、一次性费用（开模/打样/实施）、年度服务费/售后费、返利条款、备注。

### 2. 采购订单行（对应采购订单模板，用于价格趋势）

订单号、行号、供应商、物料、下单日期、承诺到货日期、实际到货日期、订单数量、实收数量、单位、币种、单价、含税口径、税率、交货仓、附加费、行状态（正常/取消/退货/红冲）。

取消行不得计入采购；退货、红冲、部分收货、事后改价要先定义处理规则再算。

### 3. 供应商绩效（对应供应商评分模板）

供应商、期间、工厂/基地、物料族、考核订单行数、准时行数、足量行数、收货数、检验合格数/退货数、不良数或 PPM、客诉数、逃逸数、未关闭 CAPA、超期 CAPA、承诺月产能、已验证月产能、提前期均值与标准差、审厂状态、强制门槛状态。

"准时"按哪个日期算（客户要求到货日 / 供应商确认到货日 / 发货日）必须全表统一。

### 4. 库存与需求（对应库存快照模板）

快照日期、仓库、物料、规格、账面库存、冻结/质检库存、已分配库存、在途库存、未交订单、欠货数、历史消耗/销量、预测、单位、提前期均值与标准差、盘点周期、服务水平目标、MOQ、订货倍数、保质期、失效日期、可替代料组。

可用库存 ≠ 账面库存：`可用 = 账面 − 冻结 − 已分配`。

### 5. 跨境物流报价（对应物流报价模板）

报价方、运输方式（海运整柜/拼箱/空运/铁运/卡车）、起运地、目的地、港口对、柜型或计费重量口径、币种、基础运费、起运港杂、目的港杂、燃油/旺季附加费、保险、报关费、关税承担方、增值税承担方、免堆免箱期、滞箱滞港规则、运输时效、班期频次、报价有效期、贸易术语、费用不含项、HS 编码状态、原产地状态、合规状态。

## 五、缺失值六态（严禁混用）

- `missing` 没提供
- `N/A` 该字段不适用
- `未披露` 供应商拒绝或暂未提供
- `有争议` 多个来源打架
- `暂定` 未经核实的临时值
- `0` 经过确认的数值零

决策级商业数据与门槛数据不得臆造填补；确需填补只能放在显式命名的"假设情景"里并标注。

## 六、供应商与物料主体归一

- 供应商要区分：法律主体（合同章）、经营品牌名、工厂地址、母公司、代工厂；授标和评分主体要写明是哪一层。
- 物料要确认是否等效：同型号不同品牌、不同等级、改版件不能直接同组比价；等效性存疑列入先决条件。

## 七、计算前必做的 10 项对账

1. 统计来源行数、纳入行数、剔除行数、未匹配行数；
2. 数量与金额合计与原始表范围核对；
3. 检查重复的订单号/报价单号/发票号；
4. 归一化后单位与币种是否一致；
5. 报价是否在有效期内，过期报价单独标注；
6. 检查负数量、负价格与异常零值；
7. 取消、退货、红冲、改价行的处理是否一致；
8. 供应商/物料/仓库映射是否都能对上；
9. 评分权重合计是否等于 1，评分方向（越高越好/越低越好）是否正确；
10. 异常行进异常表，不得静默丢弃。

报告中写明：**分母口径**（剔除之后到底按多少行、多少金额在算）。
