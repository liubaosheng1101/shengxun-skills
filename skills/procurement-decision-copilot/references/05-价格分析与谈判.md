# 05 · 价格分析与谈判

适用于：判断报价贵不贵、采购价格涨跌跟踪、涨价函应对、should-cost 拆解、谈判目标设定。

## 一、价格分析的四条证据链

按可信度组合使用，不要只靠一条：

1. **内部历史价**：自己的订单/发票数据（脚本 price 模式，加权均价、PPV、指数、波动率）；
2. **市场基准**：大宗商品期货/现货、行业指数、第三方价格（注明等级、区域、含税口径、滞后关系）；
3. **成本结构**：should-cost 拆解（原材料 + 加工 + 能源 + 人工 + 制造费用 + 销管研 + 利润）；
4. **竞争报价**：归一化后的多家供应商报价离散度。

内部数据最有谈判证据力；市场指数只作参考点，公开报价不等于你能成交的价。

## 二、历史价分析要点（脚本 price）

- 用数量加权均价，不用简单平均；
- 先做数据清洗：取消行、退货红冲、改价行、一次性费用、试样单、补差价单分别处理；
- 规格/供应商/工厂结构变化大时，先做结构调整再谈涨跌（价差桥，见 `03-计算公式手册.md`）；
- 输出至少包含：总 WAP、分月 WAP 与环比、PPV、CV 波动率、供应商金额占比；
- 数据少于 3 个周期不下趋势结论，只报事实。

## 三、市场基准对齐清单

基准价必须与采购实物对齐：**等级/牌号、交货地、币种、含税口径、合约月份、定价滞后机制**。例如豆粕、有色、化工原料的现货价与期货价、港口价与到厂价差一个口径结论就不同。

联动关系要验证：历史价格与指数是否真同向、滞后多久、合同有没有约定调价公式；不能因两张图看着像就主张成本传导。

## 四、Should-cost（应该成本）拆解

拿不到精确数据时，用可标注的假设做区间模型：

1. **原材料**：单件用量（含损耗率）× 材料单价 − 可回收废料价值；
2. **加工**：设备节拍 × 单位机时费率（折旧、能耗、厂房分摊）；
3. **人工**：单件工时 × 综合工时成本；
5. **能源与辅料**：耗电/气/水、耗材；
6. **制造费用、销管研、财务费用、利润**：按行业合理区间；
7. 包装、运输、模具摊销另列。

产出表达："在材料 X 元/kg、良率 96%、机时费率 Y 元/小时的假设下，合理不含税成本区间为 a–b 元；供应商报价高出区间上限 12%，差异主要集中在加工费率假设，需用其设备稼动数据验证。"

## 五、应对涨价函

1. 要求供应商书面提供**成本驱动证据**：材料涨价的牌号与区间、占成本比例、传导比例；
2. 用价差桥核算：原材料涨多少、其 BOM 占比多少、要求涨幅与成本涨幅是否匹配；
3. 检查合同：锁价期、调价触发条款、上下限、通知期；
4. 给组合回应而非单纯拒绝/接受：
   - 接受部分（证据充分的部分）+ 拒绝部分（搭车涨价）；
   - 用量、承诺、账期、预付款换价格；
   - 设阶梯：先临时涨、季度回看、指数联动公式化；
   - 保留第二供应源询价作为 BATNA。

## 六、谈判准备表（每次谈判产出）

| 项目 | 内容 |
|---|---|
| 目标价 | 基于历史价/基准/should-cost 得出，写明口径 |
| 开局锚点 | 第一轮出价与理由 |
| 底线（walk-away） | 超过什么条件就走第二方案 |
| 可交换筹码 | 量、份额、账期、付款方式、长协、预付款、联合降本、降规格 |
| 对方可能诉求 | 原料转嫁、MOQ 提高、缩短账期、老品退场 |
| BATNA | 谈不成的最佳替代：备选供应商/替代料/延后采购 |
| 时间压力 | 双方报价有效期、库存可支撑天数、行情窗口 |

## 七、采购时机判断

- 趋势 + 驱动因素 + 库存窗口三要素同时看，不预测行情方向做投机承诺；
- 结论形式是行动规则，例如："当前价高于近 6 月 WAP 8%，但低于近 3 月均值 3%；库存可覆盖 42 天，建议先按 30 天用量小批采购，若指数回落到 X 以下补至 60 天量"；
- 不提供金融套保建议；如用户提出套期保值，明确转交财务/专业机构。

## 八、表达红线

- 节降数字必须同口径（净价对净价），一次性费用与账期收益分开；
- 不把谈判结果记成"预计年降 XX%"，要写成"自 X 月起净单价调整为 X，按未来 12 个月预测需求量测算年节降 X 元（假设：需求 X、结构不变）"；
- 市场数据必带来源、日期、口径与访问日期。
