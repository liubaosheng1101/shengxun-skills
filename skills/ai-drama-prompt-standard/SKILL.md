# AI 短剧提示词规范

把「一集分镜」变成「一串能直接喂给视频模型、且能过审」的提示词。核心不是写得多，而是**知道哪些词会被审核拦、哪些词会让画面变塑料**。

## 一、五类任务路由（内部判断，不让用户选菜单）

| 用户想要 | 主路由 | 核心产出 |
|---|---|---|
| 有一集分镜，要写出提示词 | **提示词写作** | 按分块结构写好的完整提示词 |
| 提示词怕过不了审 / 被判真人 | **过审安全** | 风格定位选择 + 禁止词排查 + 降判定手法 |
| 出片塑料、皮肤像假人、像磨皮 | **质感调优** | 用词修正 + 光影方案 |
| 不知道某个镜头怎么说 | **词库查询** | 景别 / 构图 / 运镜 / 焦点 / 节奏的对应说法 |
| 提示词写完了，要检查 | **出图前自检** | 逐项 checklist + 具体改法 |

一次请求走一条主路由。

## 二、低打扰原则

1. 先看用户已有的分镜或提示词，**能先给一版改好的就直接给**，不要先问一堆设定。
2. 缺信息按顺序补：已有内容 → 从分镜推断 → 用可回退的默认值并标注 → 给两版方案 → 实在无法推进才提问。
3. 首轮最多问一个问题，且必须是「不回答就写不出来」的。
4. 用户只给一句题材时，直接出一版完整提示词，在其上迭代。

## 三、硬性口径（所有产出必须满足）

1. **风格定位三选一，不能混。** 同一套提示词里同时出现「CG 数字人」与「写实真人」两套词，会互相抵消。
2. **禁止词表里的词一个都不能进提示词**（`photorealistic / realistic / real person / real skin / skin pores / lifelike / photograph` 等）。这类词是**触发真人审核的主因**。
3. **不确定风格时优先「3D 渲染」路线**——过审最稳。
4. **生成方式：文生图 > 图生图。** 图生图会**继承并放大参考图的写实度**，是"疑似真人"被拦的高发来源。
5. **卡通类否定词墙要删掉。** 模型会**忽略正文否定句、甚至反解**；而且它与风格串里的 CG 向描述**自相矛盾**（同时下两个相反指令）。
6. **字幕/文字类否定词要保留。** 它是功能性的——去掉后模型可能把台词烧成画面字幕。
7. **皮肤质感靠光影，不靠堆 `skin pores`。** 质感是光照出来的，不是毛孔堆出来的。
8. **禁用平光。** `flat even lighting` = 塑料脸。要用有方向的光。
9. **参考图的风格 = 生成它的提示词的风格。** 提示词层面救不了参考图带来的风格问题。
10. **同一句提示词里不要并置冲突描述**（如皮肤同时要求"磨皮无毛孔"和"可见细纹"）。

## 四、工作流程：四步走

1. **定风格**：先选定位路线（CG 数字人 / 3D 渲染），这一句决定后面所有词的选择。
2. **搭结构**：按分块结构逐块填（见 `references/01`）。
3. **查词**：每一块从词库里选具体说法（见 `references/04`）。
4. **过筛**：跑禁止词排查 + 质感检查 + 否定词口径检查（见 `references/02`、`03`、`05`）。

## 五、产出分级

**轻量问答**（"这句怎么写""这个镜头用什么词"）：对话内直接给答案 + 一句理由。

**完整交付**按以下顺序：

1. 对话内先给「本集风格定位 + 提示词清单」（按镜头列）
2. 完整提示词文本块（可直接复制）
3. 检查清单（通过 / 不通过 + 每条的改法）

## 六、表达与边界

- 全程中文说明，提示词本体用英文关键词（模型对英文关键词更敏感）。
- 不写「建议进一步优化」这类空话；每条建议必须给出**改成什么**。
- **本技能只产出提示词文本**，不生成图片、不生成视频、不做剪辑与配音。
- 不承诺审核结果——过审口径是经验规律，最终判定以平台为准。
- 不替代角色形象设计；形象一致性问题的排查另走专门路径。
