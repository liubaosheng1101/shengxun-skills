# 05 · 出图前自检清单

**逐项过。不通过的要给具体改法，不要只标"不通过"。**

## 一、风格与合规（先过这组，不通过就别往下走）

| # | 检查项 | 不通过怎么改 |
|---|---|---|
| 1 | 风格定位**只用一套**（CG 数字人 / 3D 渲染） | 删掉另一套的定位词。特别注意 `hyperrealistic` 与 `NOT photorealistic` **不能并置** |
| 2 | 全文**无禁止词** | 逐个删：`photorealistic / realistic / real person / real chinese people / real skin / natural skin / skin pores / skin imperfections / lifelike / photo-like / photograph / portrait photography` |
| 3 | 未走"写实真人"路线 | 换成 CG 数字人或 3D 渲染 |
| 4 | **卡通类否定词已删** | 删掉 `NOT cartoon / NOT anime / NOT cel-shaded / NOT 3D animated film / NOT flat animation / NOT illustration`（模型会忽略或反解，且与风格串矛盾） |
| 5 | **字幕类否定词保留** | 确认有 `no subtitles / no text overlay / no burned-in text` |

## 二、质感（塑料感 / 假人感）

| # | 检查项 | 不通过怎么改 |
|---|---|---|
| 6 | 皮肤词**无写实向** | 删 `skin pores / skin imperfections / realistic skin texture` |
| 7 | 皮肤词**无磨皮向** | 删 `flawless / blemish-free / clean smooth / no pores / airbrushed` |
| 8 | 有 `subtle skin micro-texture` 或等效描述 | 补上，用 `subtle` 级别 |
| 9 | 有 `subsurface scattering`（或等效通透感描述） | 补在 `[LIGHTING]` 里 |
| 10 | **无平光** | 把 `flat even lighting` 换成 `soft directional key light` |
| 11 | 有轮廓光 | 补 `soft rim light` |
| 12 | 年龄与质感匹配 | 老年角色**删掉磨皮词**，补皱纹 / 皮肤松弛 / 老年斑类描述 |

## 三、结构完整性

| # | 检查项 | 不通过怎么改 |
|---|---|---|
| 13 | 分块**齐全**（12 块） | `[CAMERA]` `[FOCUS]` `[RHYTHM]` 是最常被漏的三块 |
| 14 | 画幅在 `[STYLE]` 与 `[SHOT]` 都写了 | 补上，9:16 竖屏 |
| 15 | `[SHOT]` 有字幕安全区 | 补 `bottom subtitle safe zone` |
| 16 | `[CHARACTER]` 里**没有表情词** | 把表情移到 `[EXPRESSION]` |
| 17 | `[CHARACTER]` 里**没有情绪词** | 同上；情绪要落成可见的微表情 |
| 18 | `[ACTION]` 有**可见结果** | "伸手"→"手够到门把并握住" |
| 19 | `[SCENE]` 只写镜头能看到的东西 | 删掉心理、感受类描述 |

## 四、可执行性

| # | 检查项 | 不通过怎么改 |
|---|---|---|
| 20 | **动作量与时长匹配** | 短镜只留一个转折；动作多就加时长 |
| 21 | 运镜复杂度与表演复杂度匹配 | 表演复杂的镜头改成 `locked-off static` 或 `slow push in` |
| 22 | 台词是**完整原句** | 把省略号摘要换成完整台词 |
| 23 | 台词念完有换气空间 | 时长按台词字数算够 |
| 24 | 多人场景**按人物点名** | 把代词改成角色名，避免所有人同步变脸 |

## 五、跨镜一致性

| # | 检查项 | 不通过怎么改 |
|---|---|---|
| 25 | 本集全镜的风格串**完全一致** | 统一成同一串（不要有的镜头短、有的长） |
| 26 | 同一角色的外观描述**跨镜一致** | 服装 / 发型只在 `[CHARACTER]` 写，不逐镜改 |
| 27 | 投喂的参考图**来源链统一** | 不要一部分用文生图产物、一部分用图生图派生 |
| 28 | `[RHYTHM]` 在整集里有起伏 | 不能全是 `climax`；要有 hook / setup / build / climax / cliffhanger 分布 |

## 六、输出格式

**自检结果这样呈现**：

```
【风格与合规】通过 ✅
【质感】不通过：
· 第 8 项 缺 subtle skin micro-texture → 在 [STYLE] 的皮肤段补 "soft digital skin, subtle skin micro-texture"
· 第 10 项 [LIGHTING] 写的是 flat even lighting → 换成 "soft directional key light, local specular highlights"
【结构】不通过：
· 第 13 项 缺 [RHYTHM] → 补 "[RHYTHM] build, editing pace slow motion, emotion curve rising"
【可执行】通过 ✅
【跨镜一致】通过 ✅
```

**每条都要给"改成什么"**，不要写"建议优化"。

## 七、最后一遍

过完全部 28 项后，再问自己两个问题：

1. **如果模型完全听不懂"情绪"，它只按字面执行——这句话它能执行成什么？**
2. **如果审核只做图像识别、不做关键词匹配——这套词会出什么样的图？**

这两个问题能筛掉大部分"写得很文学、但模型执行不出来"的提示词。
