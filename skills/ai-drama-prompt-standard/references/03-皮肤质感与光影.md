# 03 · 皮肤质感与光影

「塑料感」「磨皮重」「像假人」的成因通常不在模型，而在**皮肤词写错方向、或用了平光**。

## 一、两种错误的皮肤写法

### ❌ 错误一：堆"毛孔"词

```
skin pores, skin imperfections, realistic skin texture, real skin
```

这类词属于**写实向**，会把风格往实拍推，直接踩过审禁止词（见 `02`）。

### ❌ 错误二：堆"磨皮"词

```
flawless, blemish-free, clean smooth, even-toned, airbrushed
```

实测反馈：**磨皮太厉害、没有真人自然感**。磨皮词把皮肤纹理与天然肤色变化全部磨平，脸会变成"塑料壳"。

## 二、正确做法：安全皮肤词库 + 光影

### 安全皮肤词库（不越写实线，也不塑料）

```
soft digital skin, subtle skin micro-texture, soft skin translucency,
subtle subsurface scattering, soft tonal variation, natural skin sheen
```

**要点**：用 `subtle`（细微）级别的词描述质感，**不要用 "visible / clear / obvious" 这类强调可见度的词**——那会把模型推向写实。

### 光影做质感（比堆词有效得多）

```
[LIGHTING] soft directional key light,
subtle subsurface scattering on cheeks and nose,
soft rim light, localized specular highlights
```

| 做法 | 效果 |
|---|---|
| ✅ `soft directional key light` | 制造微阴影 → 有立体感 → 不塑料 |
| ✅ `subsurface scattering`（皮下散射） | 皮肤通透感 |
| ✅ `soft rim light` | 轮廓分离，人物"立"起来 |
| ❌ `flat even lighting` | **平光 = 塑料脸**，必须避免 |

**核心认知：皮肤质感是光照出来的，不是毛孔堆出来的。**

## 三、负向提示词（模型支持时用）

```
plastic skin, waxy skin, airbrushed, oversmoothed,
doll, mannequin, beauty filter, instagram filter
```

⚠️ 但记住：**正文否定句会被模型忽略甚至反解**（见 `02` 第六节）。负向词只在**模型有专门的负向提示词字段**时才有意义，写在正文里的 `NOT xxx` 基本无效。

## 四、一个真实的调优案例

**问题**：某角色的镜头脸部斑点太明显，后续镜头不允许再有。

**第一版改法（错）**：把肤质句写成

```
flawless blemish-free complexion, clean smooth even-toned skin, no pores
```

→ 斑点没了，但**塑料感上来了**：`flawless` / `clean smooth` / `no pores` 都是磨皮方向。

**第二版改法（对）**：**只换掉磨皮部分，保留去斑部分**

```
natural realistic skin texture with visible fine detail and lifelike tone variation,
no freckles, no age spots, no skin blemishes
```

→ 斑点不见了，皮肤仍有真实纹理。

**关键区分**：

| 目标 | 该用的词 |
|---|---|
| **去斑 / 去瑕疵** | `no freckles, no age spots, no skin blemishes` |
| **保质感** | `natural realistic skin texture with visible fine detail, lifelike tone variation` |
| **不要用的** | `flawless` / `clean smooth` / `no pores`（这些是磨皮，会连质感一起磨掉） |

## 五、年龄与质感的关系

⚠️ **磨皮词不能用在老年角色上。**

老年角色的年龄**必须靠皱纹 / 皮肤松弛 / 老年斑这些痕迹读出来**。而 `smooth idealized skin` 这类词会把这些痕迹磨平——**那句是为年轻角色调的**。

老年角色应该写年龄痕迹向的描述：

```
heavy hooded eyelids, crow's feet, prominent forehead creases,
weathered skin with visible pores, age spots and uneven natural texture,
slightly sagging jawline, natural grey-white stubble
```

## 六、风格与质感的边界

⚠️ **皮肤词只能解决"质感"，解决不了"风格"。**

如果出片整体偏卡通/插画，那**不是皮肤词的问题**，而是**参考图带来的风格**（参考图的风格 = 生成它的提示词的风格）。这种情况下改皮肤词没有任何用。

判别方法：

| 症状 | 该去哪一层改 |
|---|---|
| 皮肤像塑料、磨皮重、平光 | 皮肤词 + 光影（本文件） |
| **整体偏卡通 / 插画 / 3D 动画感** | **参考图的风格**（不在提示词层） |

## 七、自检

- [ ] 皮肤词里**没有**写实向词（pores / imperfections / realistic skin）
- [ ] 皮肤词里**没有**磨皮向词（flawless / blemish-free / clean smooth / no pores）
- [ ] 质感用 `subtle` 级别描述
- [ ] 光源是**有方向**的，不是 `flat even lighting`
- [ ] 有 `subsurface scattering` 或等效的通透感描述
- [ ] 老年角色**没有**用磨皮词
- [ ] 若问题是"整体卡通"，已确认不是皮肤词能解决的
