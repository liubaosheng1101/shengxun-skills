# 01 · 提示词分块结构

分块的好处：**每一块只回答一个问题**。写的时候能看出哪块漏了，出问题时也能定位到是哪一块写坏了。

## 一、十二块结构模板

```
[STYLE]      整体风格与技术规格
[SCENE]      环境与时空
[SHOT]       景别与构图
[CAMERA]     运镜
[CHARACTER]  角色外观
[ACTION]     动作
[FOCUS]      焦点与景深
[EXPRESSION] 表情与微表情
[LIGHTING]   光影与色调
[RHYTHM]     节奏定位
[AUDIO]      声音与台词
[DURATION]   时长
```

可直接复制填空（`{}` 为待填槽位）：

```
[STYLE] {风格定位串}, {题材调性}, {画幅}, {光效串}, same face, locked facial structure, cinematic digital realism
[SCENE] {location}, {time of day}, {weather}, {atmosphere}
[SHOT] {画幅}, {shot_size}, {composition_rule}, {foreground_element}, subject in upper-third, bottom subtitle safe zone
[CAMERA] {camera_movement}, speed {speed}, stability {stability}, movement synced with {emotion_beat}
[CHARACTER] {Name}, {age} {ethnicity} {gender}, {facial_features} / {costume} / {hairstyle_accessories}, {prop}
[ACTION] {subject} {specific_action}, {interaction}, {visible_consequence}
[FOCUS] focus on {focus_point}, {depth_of_field}, {focus_rack}, bokeh on {background}
[EXPRESSION] - {Character}: {emotion}, {micro_expression}, timing at {N}s
[LIGHTING] {color_tone}, {key_light}, {fill_light}, {rim_light}
[RHYTHM] {rhythm_role}, editing pace {editing_pace}, emotion curve {emotion_curve}, transition {transition}
[AUDIO] {dialogue_or_sfx}, sync at {sync_point}
[DURATION] {N} seconds
```

## 二、每块写什么

| 块 | 回答的问题 | 关键要求 |
|---|---|---|
| `[STYLE]` | 这是什么风格、什么画幅、什么调性 | **决定成败的一块**。定位词必须与禁止词互斥（见 `02`） |
| `[SCENE]` | 在哪、什么时间、什么天气氛围 | 只写**镜头能看到**的；缺了会继承上一镜的场景 |
| `[SHOT]` | 多近、怎么构图 | 竖屏剧固定写画幅与字幕安全区 |
| `[CAMERA]` | 镜头怎么动 | **人物表演复杂的镜头优先用静止或缓推**，运镜多了模型顾此失彼 |
| `[CHARACTER]` | 谁、什么年龄、什么外观 | **不要在这里写表情**（表情归 `[EXPRESSION]`），也不写"情绪" |
| `[ACTION]` | 在做什么、和谁互动、结果如何 | 动作要**看得见结果**（"伸手"不够，要"手够到门把并握住"） |
| `[FOCUS]` | 焦点在哪、景深多深 | 竖屏特写用浅景深；信息镜用深景深 |
| `[EXPRESSION]` | 什么情绪、怎么体现、什么时候变 | 写**可见的**微表情，不写"内心复杂" |
| `[LIGHTING]` | 什么色调、主光辅光轮廓光 | **有方向的光**，不用平光 |
| `[RHYTHM]` | 这一段在整集里承担什么 | 钩子 / 铺垫 / 蓄力 / 爆发 / 反转 / 收尾 / 结尾钩子 |
| `[AUDIO]` | 说什么、什么音效、什么时候同步 | **台词要写完整原句**，不要写省略号摘要 |
| `[DURATION]` | 几秒 | 时长决定动作量，短镜只留一个转折 |

## 三、风格串：两套通用模板（**不能混用**）

### 方案 A · CG 数字人（现代/都市题材）

```
cinematic digital human, hyperrealistic CG character, east asian facial features,
no anime, no manga, no cartoon, {题材调性}, {色调},
soft digital skin, subtle skin micro-texture, soft skin translucency,
subtle subsurface scattering, {画幅}, soft rim lighting, subtle fill light,
same face, locked facial structure, cinematic digital realism, subtle film grain
```

### 方案 B · 3D 渲染（**过审最稳**）

```
stylized 3D character render, premium stylized 3D render,
NOT photorealistic, NOT photograph, {题材调性}, {色调},
smooth idealized skin texture, soft cel-shaded volumetric lighting, {画幅}
```

### ⛔ 两套不能混

- 方案 A 用「逼真」路线，方案 B 用「渲染」路线。
- **同一句提示词里同时出现两套的定位词，会互相抵消**，出片四不像。
- 尤其注意：**不要把 `NOT photorealistic` 与 `hyperrealistic` 并置**。

### ⛔ 第三套（写实真人）不可用

`photorealistic, real chinese people` 这条路**会触发真人审核**，禁止使用（详见 `02`）。

## 四、跨块的一致性要求

| 要求 | 说明 |
|---|---|
| 画幅在 `[STYLE]` 与 `[SHOT]` 都写 | 避免一处被模型忽略 |
| 角色名在 `[CHARACTER]` 与 `[EXPRESSION]` 一致 | 多人场景必须**按人物点名**，不能用代词 |
| 服装只在 `[CHARACTER]` 写 | 不要在多块重复，重复易冲突 |
| 时长与动作量匹配 | 4 秒最多一个转折；动作多必须加时长 |
| 台词与 `[DURATION]` 匹配 | 台词念完要留换气空间 |

## 五、自检

- [ ] 十二块齐全，没有漏块（`[CAMERA]` `[FOCUS]` `[RHYTHM]` 最常被漏）
- [ ] 风格定位**只用一套**，未混用
- [ ] `[CHARACTER]` 里没有表情词
- [ ] `[ACTION]` 有可见结果
- [ ] 画幅在风格块与镜头块都写了
- [ ] 多人场景已按人物点名
- [ ] 台词是完整原句
