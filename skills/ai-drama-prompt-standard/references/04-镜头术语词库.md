# 04 · 镜头术语词库

影视通用术语，按功能分类。写提示词时按需查。

## 一、景别（`[SHOT]` · shot_size）

| 中文 | 英文关键词 | 用途 |
|---|---|---|
| 极特写 | `extreme close-up` | 眼、手、道具等局部；张力最大 |
| 特写 | `close-up` | 面部表情 |
| 近景 | `medium close-up` | 胸部以上，对话常用 |
| 中景 | `medium shot` | 腰部以上，兼顾动作与表情 |
| 中远景 | `medium wide` | 全身入画但仍有环境 |
| 远景 | `wide shot` | 交代空间关系 |
| 极远景 | `extreme wide shot` | 环境为主，人物极小 |

**竖屏剧提示**：竖屏（9:16）横向空间窄，**优先用近景与中景**；远景人物会很小，且底部要留字幕安全区。

## 二、构图（`[SHOT]` · composition_rule / foreground_element）

| 字段 | 可选值 |
|---|---|
| composition_rule | `rule of thirds subject left` / `rule of thirds subject right` / `centered symmetrical` / `off-center` |
| foreground_element | `door frame` / `window` / `leaves` / `fabric curtain` / `blurred crowd` / `none` |

**用法**：加一个前景元素能快速做出层次感——`door frame`（门框）、`fabric curtain`（纱帘）最常用。

## 三、运镜（`[CAMERA]`）

| 运镜 | 英文关键词 | 适用场景 |
|---|---|---|
| 静止锁焦 | `locked-off static` | 对峙、压迫、冷静陈述 |
| 慢推 | `slow push in` | 情绪聚焦、真相浮现 |
| 急推 | `fast push in` | 震惊、顿悟 |
| 慢拉 | `slow pull out` | 孤独、抽离、崩塌 |
| 手持跟拍 | `handheld tracking, micro shake` | 追逐、逃亡、紧张 |
| 摇镜 | `pan left` / `pan right` | 展示环境、跟随 |
| 甩镜 | `whip pan, motion blur` | 快节奏转场 |
| 升降 | `crane up` / `crane down` | 竖屏情绪外化 |
| 眩晕变焦 | `dolly zoom, vertigo effect` | 极度震惊 |
| 环绕 | `orbit around subject` | 人物出场 |

| 字段 | 可选值 |
|---|---|
| speed | `slow` / `medium` / `fast` |
| stability | `locked-off` / `gimbal smooth` / `handheld micro shake` |

⚠️ **重要实践原则**：**人物表演复杂的镜头，优先用静止或缓推。**

人物情绪表演本身已经携带大量动作信息。如果同时加入快速推进、环绕、甩镜、大幅移动、人物走动、复杂手部动作，**模型需要同时处理的信息过多，很容易导致人物表演失控**。

**推荐**：测试人物表演时统一用 `locked-off static` 或 `slow push in`。**先把"戏"演对，再加镜头语言。**

## 四、焦点（`[FOCUS]`）

| 字段 | 可选值 |
|---|---|
| focus_point | `subject's eyes` / `hand holding object` / `face` / `background detail` |
| depth_of_field | `shallow DOF` / `medium DOF` / `deep DOF` |
| focus_rack | `static` / `rack from A to B` |
| bokeh | `bokeh on {background}` |

**用法**：

- **特写 / 情绪镜**用 `shallow DOF`，焦点落在眼睛。
- **信息镜**（要看清单据、屏幕、环境细节）用 `deep DOF`。
- **移焦**（`rack from A to B`）用于"从道具切到人物反应"这类叙事转折。

## 五、节奏定位（`[RHYTHM]`）

| 节奏角色 | 英文 | 剪辑处理 |
|---|---|---|
| 钩子 | `hook` | 前 3 秒强冲击，快剪 |
| 铺垫 | `setup` | 正常节奏 |
| 蓄力 | `build` | 慢镜 / 静音，压制 |
| 爆发 | `climax` | 快剪 + 强音效 |
| 反转 | `reversal` | 慢镜 + 静音 + 定格 |
| 收尾 | `resolution` | 节奏放缓 |
| 结尾钩子 | `cliffhanger` | 结尾留悬念 |

| 字段 | 可选值 |
|---|---|
| editing_pace | `fast cut` / `normal` / `slow motion` / `freeze frame` |
| emotion_curve | `rising` / `falling` / `peak` / `valley` |
| transition | `J-cut audio lead` / `whip pan` / `match cut` / `hard cut` / `fade to black` / `fade in` |

**用法**：`[RHYTHM]` 是**给整集定调**的块，不是单镜的装饰。同一集里节奏角色要有起伏（不能全是 `climax`）。

## 六、声音（`[AUDIO]`）

| 项 | 写法 |
|---|---|
| 台词 | 写**完整原句** + 说话人 + 时间码 |
| 音效 | `{具体音效}`，如 `door creaks open`、`glass shatters` |
| 同步点 | `sync at {N}s` |

⚠️ **台词必须写完整原句**，不要写省略号摘要（如「楚小姐…天才」）。模型只拿到摘要，配音必然含糊——**这是"所有配音都不自然"的常见根因**。

⚠️ 一句话常需拆成多行（按原节奏分行输出），**逐行写正好让模型按原节奏念，不要合并成一行**。

## 七、速查：一个镜头最少的必填项

```
[STYLE]   已有全局风格串（每集固定，不逐镜改）
[SCENE]   在哪、什么时候
[SHOT]    景别 + 画幅 + 字幕安全区
[CAMERA]  运镜（表演复杂时用 locked-off static）
[CHARACTER] 谁
[ACTION]  做什么（要看得见结果）
[EXPRESSION] 什么情绪（可见的微表情）
[LIGHTING] 有方向的光
[DURATION] 几秒
```
