# 01 · 跟单节奏与预警

跟单的核心不是"勤问"，而是**在对的时点问对的事**。问早了对方没有信息可给，问晚了已经来不及补救。

## 一、四个必跟节点

从下单到到货，按这条线走。每个节点有明确的"要拿到什么"：

| 节点 | 时点 | 必须拿到的东西 | 拿不到说明什么 |
|---|---|---|---|
| **订单确认** | 下单后 24–48 小时内 | 供方书面确认：收到订单、承诺交期、排产计划 | 对方可能没接单、或交期有异议 |
| **生产中期** | 交期过半或长周期订单的 1/3、2/3 处 | 生产进度、是否有异常、能否按期 | 对方在拖，或还没排产 |
| **发货确认** | 约定交期前 3–5 天 | 发货日期、物流方式、单号、装箱/装车清单 | 极可能要延期，此时还有补救窗口 |
| **到货前确认** | 发货后、到货前 1–2 天 | 预计到货时间、车辆信息、卸货要求 | 收货现场会出乱子 |

**关键判断**：如果交期前 3–5 天还拿不到"发货确认"，实际延期的概率已经很高——**这是最后的补救窗口**（可协调加急、可启用备选、可调整生产计划）。很多采购错在这一步，等到过期才反应。

## 二、预警灯号规则

用三色灯管理，规则提前定死，避免每次凭感觉判断：

| 灯号 | 触发条件 | 应做的动作 |
|---|---|---|
| **绿** | 进度正常，节点按时确认 | 按节奏跟踪，不额外打扰 |
| **黄** | ① 节点超时未确认（如 48 小时未回执）<br>② 交期前 5 天未发货<br>③ 对方主动提出交期变更<br>④ 中期进度慢于计划 | 一级催办 + 要求书面说明 + 开始找备选 |
| **红** | ① 已逾期<br>② 对方明确表示赶不上<br>③ 连续两次承诺未兑现<br>④ 涉及停线或重大损失 | 升级催办 + 启动备选 + 书面告知后果 + 评估索赔 |

**升级触发条件要预设**，不要等出了事再讨论"要不要升级"。建议在黄灯时就把"再拖 N 天就升级"写下来并告知对方。

## 三、不同品类要用不同的跟单密度

不是所有订单都值得同样强度地跟。按风险分级：

| 品类特征 | 跟单密度 | 理由 |
|---|---|---|
| 长周期、定制、非标件 | 高（每个节点都跟，中期至少 2 次） | 一旦延期无法补救，无现货可替代 |
| 危化品、需运输资质 | 高（额外确认运输安排与资质有效期） | 卡在物流和资质上很常见，且不能临时换 |
| 首次合作的新供应商 | 高（前 2–3 单都要盯紧） | 不了解其履约习惯，试单期最容易出问题 |
| 标准品、现货充足、多供应源 | 低（只在发货前确认一次） | 出问题随时可换，不值得投入管理精力 |
| 已稳定合作的老供应商 | 低（异常时才跟） | 历史履约良好，过度跟踪反而伤关系 |

**原则**：把跟单精力压在"出问题就补不回来"的订单上。

## 四、跟踪表建议字段

不需要复杂系统，一张表就够。关键是让"该跟没跟"和"逾期未发现"变得可见：

| 字段 | 说明 |
|---|---|
| 合同号 / 订单号 | 唯一标识 |
| 供应商 | 简称即可 |
| 品名规格 | 便于识别 |
| 数量 / 单位 | 含溢短装约定 |
| 合同金额 | 索赔计算基数 |
| 约定交期 | 计算逾期天数的基准 |
| **最新承诺交期** | 对方每次改口都记这里，累积下来就是"跳票记录" |
| 当前节点 | 未排产 / 生产中 / 已发货 / 已到货 |
| 灯号 | 绿 / 黄 / 红 |
| 最近一次跟踪日期 | 防止"忘了跟" |
| 逾期天数 | = 今天 − 约定交期（未到货时） |
| 备注 | 关键沟通结论、对方联系人 |

**"最新承诺交期"这一列最容易被省掉，但它恰恰是最有用的**——当对方第三次改口时，这列累积的记录本身就是交涉证据。

## 五、每日 / 每周的固定动作

| 频率 | 做什么 | 耗时 |
|---|---|---|
| 每天 | 扫一眼红色灯号，看有无新增逾期 | 2 分钟 |
| 每周 | 更新一次在途订单进度；检查黄灯是否该升红灯 | 10 分钟 |
| 每周 | 检查"长期无进展"订单（超过一个跟踪周期没拿到任何进展） | 5 分钟 |
| 每月 | 统计各供应商逾期率，作为后续授标参考 | 20 分钟 |

**"长期无进展"是最隐蔽的风险**：对方没说不做，但你也没拿到任何确认——这类订单往往在某天突然告知"做不了"，此时已经彻底来不及。规则：**超过一个跟踪周期（按品类定，通常 7 天）没拿到任何实质进展的，直接升黄灯并要求书面说明。**
