# 06 · 函件与话术模板

括号内为待填项。发出前逐项检查：**双方主体全称、合同编号、日期、金额、期限**——这五项写错一项，函件的证据效力就打折。

## 一、函件的通用结构

```
① 标题（事由明确）
② 收件方全称 + 我方全称
③ 合同/订单编号与标的
④ 事实陈述（只写有证据的，按时间轴）
⑤ 依据（引用合同条款编号与原文）
⑥ 主张/要求（明确、可执行、有期限）
⑦ 保留权利声明
⑧ 落款、日期、联系方式
⑨ 附件清单
```

**三条纪律**：
- **不用形容词**。"贵司严重违约、极其不负责" 这类表述对主张毫无帮助，还可能被认定为不当言论。只写事实与条款。
- **不用威胁**。写"将采取一切必要措施"不如写"将依据合同第 X 条主张逾期违约金"。具体才有力量，含糊反而显得虚张声势。
- **不写没把握的事**。函件一旦发出就是证据，其中任何不准确的内容都会被对方拿来反击。

## 二、催货函（一级 · 常规推进）

> 适用于：黄灯初期，尚未逾期或逾期 1–3 天

```
关于【合同编号】项下货物交期的沟通函

【供应商全称】：

贵司与我司于【日期】签订编号【合同编号】的采购合同，约定
【品名规格】共【数量】，交货日期为【约定交期】。

截至本函发出之日，我司尚未收到发货通知。为此，请贵司于
【回复期限，如 1 个工作日内】书面确认以下事项：

1. 当前生产/备货进度；
2. 预计发货日期；
3. 预计到货日期；
4. 如存在影响交期的因素，请说明具体原因及解决措施。

烦请书面回复。

【我方全称】
【日期】
联系人：【姓名】 电话：【号码】
```

## 三、催货函（二级 · 明确后果）

> 适用于：一级催办无实质进展，或已逾期

```
关于【合同编号】项下货物逾期的催告函

【供应商全称】：

一、事实

贵司与我司于【日期】签订编号【合同编号】的采购合同，约定如下：

  品名规格：【】
  数量：【】
  合同金额：【】
  约定交货日期：【】

我司分别于【日期1】、【日期2】以【方式：邮件/微信】催办，
贵司【日期1】承诺【承诺内容】，【日期2】承诺【承诺内容】，
截至本函发出之日仍未交付，已逾期【N】天。

二、依据

合同第【X】条约定："【引用原文，如：供方逾期交货的，
每逾期一日按逾期部分金额的 0.05% 向需方支付违约金】"

三、要求

1. 请贵司于【日期】前完成交付；
2. 逾期期间产生的违约金，我司将依据上述条款主张，
   初步测算为【金额】元（计算方式：逾期部分金额【】×
   日费率【】× 逾期【】天）；
3. 请于【回复期限】内书面回复交付计划。

四、权利保留

我司保留就本次逾期进一步主张权利的权利，包括但不限于
依据合同约定主张违约金、要求赔偿实际损失。

【我方全称】
【日期】
附件：合同复印件、催办记录、到货催告记录
```

## 四、质量异议通知

> 适用于：到货发现质量不合格。**必须在异议期内发出。**

```
关于【合同编号】项下货物质量异议的通知

【供应商全称】：

我司于【到货日期】收到【合同编号】项下【品名规格】
【数量】。经检验，发现以下问题：

  1. 【问题描述，如：批次号 XXXX 外观存在明显裂纹，
     详见附件照片】
  2. 【检测数据，如：按【标准编号】检验，实测值【】，
     标准要求【】】

我司已于【日期】将上述货物隔离存放，未投入使用。
按合同第【X】条约定，质量异议期为【N】日，本通知在
异议期内发出。

现要求如下：

1. 请贵司于【N】日内派员到我司现场共同确认；
2. 请于【N】日内书面提出处置方案（退货 / 换货 / 降价接收
   / 返工）；
3. 处置方案应明确：完成时限、费用承担、往返运费承担；
4. 在处置方案明确前，我司将暂停该批货物对应货款结算。

我司保留就本次质量问题主张违约金及实际损失赔偿的权利。

【我方全称】
【日期】
附件：到货签收单、照片、检验报告、封样记录
```

## 五、索赔函

> 适用于：索赔金额已测算清楚、证据链完整。

```
关于【合同编号】项下违约索赔的函

【供应商全称】：

一、事实与依据

【合同编号】合同约定：【约定内容】。
合同第【X】条约定："【条款原文】"。

贵司【违约行为，如：实际于【日期】交付，逾期 N 天 /
交付货物经检验不符合约定标准】。

二、损失与索赔金额

  1. 逾期违约金：
     逾期部分金额【】× 日费率【】× 逾期【】天 = 【】元
     （依据：合同第【X】条；逾期自【】起算至【】）

  2. 【其他损失项，如：检验费【】元、往返运费【】元、
     替代采购价差【】元】
     （依据：附件票据【编号】）

  索赔金额合计：【】元

三、主张

请贵司于【日期，通常给 10–15 个工作日】前支付上述款项，
或书面提出异议。我司可接受以下方式之一：

  □ 支付至我司账户：户名【】账号【】开户行【】
  □ 从【合同编号】未结货款中抵扣
  □ 以【数量】货物补足

四、权利保留

我司保留就本次违约进一步主张其他损失的权利，
包括但不限于【停线损失 / 下游客户索赔 / 检验费用】。

【我方全称】
【日期】
附件：合同、到货记录、检验报告、费用票据、损失证明、
      沟通记录
```

## 六、交期变更确认单

> 适用于：对方提出延期、或双方协商调整交期。**不要只在微信里"好的"——必须书面。**

```
交期变更确认单

合同编号：【】
供应商：【】
原约定交期：【】
变更后交期：【】
变更原因：【如：供方原材料到货延迟】

变更条件：
  □ 供方承担加急运输费用【】元
  □ 原逾期责任【是否保留 / 不再追究】
  □ 价格调整：【无 / 调整至【】】
  □ 追加保障条款：如再次逾期，我司有权取消订单
    并按合同第【X】条主张违约金

其他约定：
【如约定分批发货的，列出每批数量与日期】

供方确认（签章）：           需方确认（签章）：
日期：                        日期：
```

## 八、送达与留痕要点

| 方式 | 证据效力 | 建议 |
|---|---|---|
| **EMS / 挂号信** | 强（有签收记录） | 重要函件（索赔、最后通牒）必用；面单注明文件名称 |
| **电子邮件** | 强（可查收发记录） | 双方有约定邮箱的最优；保留完整邮件头 |
| **微信 / 钉钉** | 中（需证明账号归属） | 日常沟通可用；**确认对方账号可对应到具体人员** |
| **电话** | 弱 | 只能作为辅助；重要内容必须补书面 |
| **当面递交** | 中（需签收） | 让对方在副本上签收并注日期 |

**推荐做法：双通道。** 重要函件用 EMS + 邮件同时发出，微信同步告知"已发出，请查收"。三重留痕，对方很难否认收到。

**时间戳很重要**：所有沟通记录保留原始载体（不要只截图后删除），邮件不要清理，聊天记录不要删除。
