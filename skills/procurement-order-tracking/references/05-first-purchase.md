# 05 · 首采与新品导入风控

首次采购一样没买过的东西，失败成本远高于单价差异。**首采省下的钱，通常不够一次事故的零头。**

## 一、第一道闸门：技术规格必须完整

**只写名称的采购需求是首采最大的坑。** 同一个名字在不同厂家、不同标准下可能是完全不同的东西。

技术规格核对单（缺一项就要追问，不能靠"应该是那个"）：

| 维度 | 要写清的内容 | 漏写的后果 |
|---|---|---|
| **材质** | 具体牌号，不是"不锈钢"（如 316L / 304 / PTFE） | 拿到便宜但耐蚀性不够的替代品 |
| **规格尺寸** | 公称尺寸 + 关键尺寸公差 | 装不上 |
| **连接/接口方式** | 法兰标准（如 HG/T、ANSI）、螺纹规格、**公母头**、密封面形式 | 到了现场接不上，返工等几周 |
| **工作介质** | 具体介质名称，腐蚀性、是否易燃易爆 | 选材错误，安全风险 |
| **压力等级** | 设计压力 + 试验压力 | 承压不足 |
| **温度范围** | 工作温度 + 极端工况 | 密封件失效 |
| **执行标准** | 国家标准 / 行业标准 / 企业标准编号 | 验收无依据，争议时说不清 |
| **特殊要求** | 清洁度、脱脂、防爆等级、防护等级、认证 | 合规不通过 |

**操作建议**：把这张核对单直接发给供应商，要求**逐项书面确认**。对方含糊回避的项，往往是它做不到的项。

## 二、第二道闸门：供应商能力证据

首次合作，**不看承诺看证据**：

| 要核实 | 证据形式 | 常见话术陷阱 |
|---|---|---|
| 有没有做过同类产品 | 同类业绩清单（可含脱敏合同/发货记录）、产品照片、用户名单 | "我们什么都能做" = 大概率没做过同类的 |
| 技术能力 | 型式试验报告、第三方检测报告、专利、技术方案 | "报告有的" 但拿不出编号与截图 |
| 资质合规 | 生产许可、行业准入、体系认证、**有效期**在范围内 | 证书过期、认证范围不含该产品 |
| 产能与交期保障 | 排产能力说明、关键设备清单 | "随时能排产" 但没有具体日期承诺 |
| 实际主体一致 | 营业执照名称 = 报价主体 = 收款主体 = 开票主体 | 报价一家、开票另一家（后续追责极难） |

**主体一致性要特别核**：主体不一致会在质量追责、发票抵扣、法律诉讼三个阶段都出问题。

## 三、第三道闸门：试验与送检（先谈钱和周期）

首采常遇到"没有现成检测报告，需要送检"的情况。**必须在报价阶段就把三件事谈清楚**：

| 要谈的 | 关键问题 | 谈判要点 |
|---|---|---|
| **谁出钱** | 检测费由谁承担 | 首采时供方为拿下订单通常愿意承担；若我方承担，应约定"检测通过后由供方返还"或折抵货款 |
| **多久** | 检测周期多少天 | 必须写进交期。检测周期常被漏算，导致整体工期延误 |
| **样品是否报废** | 破坏性试验会损毁样品 | 破坏性试验的样品数量、费用、是否另收费要写明；**别按"1 台"报价，实际要 2–3 台** |
| **报告归属** | 报告原件给谁 | 我方应留存报告副本，用于后续验收与追溯 |
| **不通过怎么办** | 检测不合格的处置 | 约定：供方承担费用并限期整改；我方有权取消订单且不承担损失 |

**型式试验 vs 例行试验**：
- **型式试验**：验证设计是否达标，通常一次性的、覆盖该型号
- **例行试验/出厂检验**：每批每台都做
- 首采要的是**型式试验报告**（证明这个型号设计合格）；后续到货要的是**例行试验报告**（证明这一台合格）。**两者不能互相替代**，别被"我们有报告"糊弄过去。

### 破坏性试验的处理原则

若必须做破坏性试验（样品报废）：
- 数量按"试验 + 备查 + 交付"分别计算，不要按交付数量报
- 费用单列，不并入单价（否则后续量产价格说不清）
- 试验结果要形成书面报告，作为验收依据
- 提前评估：**如果这批试验全部报废，总成本是否仍在可接受范围**——若不可接受，说明这个首采方案本身有问题

## 四、第四道闸门：小批量试用与首件验收

**首采不要直接上批量。** 推荐路径：

```
样品/试验件 → 首件验收 → 小批量试用 → 批量采购
```

| 阶段 | 数量 | 验收重点 | 通过标准 |
|---|---|---|---|
| **样品/试验件** | 1–3 件 | 尺寸、材质、外观、报告 | 逐项对照技术规格核对单 |
| **首件验收** | 首批第 1 件 | 全尺寸 + 性能 + 装配验证 | 有书面验收记录，双方签认 |
| **小批量试用** | 实际工况下运行 | 耐久性、实际适配性 | 运行 N 天/批次无异常 |
| **批量** | 按需求 | 按约定的抽检方案 | 稳定后转常规验收 |

**首件验收标准必须提前定**，不能"到货了再商量怎么算合格"。标准应包括：检验项目、检验方法、判定依据、抽样比例、不合格处置。

**小批量试用期要设终止条件**：明确"运行多少时间/多少批次无异常后转入批量"，否则容易无限期挂着。

## 五、第五道闸门：首采的风险定价

首采的成本不能只看单价，要算**总获取成本**：

| 成本项 | 首采时是否发生 | 说明 |
|---|---|---|
| 单价 | 是 | 首采单价通常高于量产价，属正常 |
| 开模/开模费/模具费 | 常发生 | 谈清归属：模具归谁、后续换供应商能否带走 |
| 检测/试验费 | 常发生 | 见第三节 |
| 试错成本 | 可能发生 | 不合格返工、停线、替换 |
| 学习成本 | 是 | 沟通、技术对接、驻场 |
| 切换成本 | 未来 | 若后续要换供应商，是否要重新验证 |

**判断原则**：如果首采单价低但试错成本高（如停线、安全事故），**应优先选择单价略高但能力证据充分的供应商**。

## 六、首采风控检查表

下单前逐项确认，任一项为"否"就要补：

- [ ] 技术规格核对单已逐项书面确认，无"应该是"的含糊项
- [ ] 供应商主体一致性已核（执照 = 报价 = 合同 = 收款 = 开票）
- [ ] 资质证书在有效期内且**认证范围覆盖该产品**
- [ ] 同类业绩有可核实的证据（不只是口头声称）
- [ ] 型式试验报告已取得（如适用），报告编号可查
- [ ] 检测费用承担、周期、样品报废数量已书面约定
- [ ] 首件验收标准已书面明确（项目 / 方法 / 判定 / 抽样）
- [ ] 小批量试用方案与终止条件已定
- [ ] 安全、环保、强制认证类要求已确认（**不得因交期紧而省略**）
- [ ] 备选供应商已初步摸底（首采失败时有退路）
- [ ] 合同已包含：质量违约责任、逾期条款、异议期、退换货条件

## 七、红线

- 涉及**安全、环保、强制认证、危化品、承压设备**的首采，规格与资质审核**不得因交期压力而降低标准**。这类物资出问题的代价远超工期。
- 不做质量终局判定，需要资质机构确认的项目（型式试验、特种设备检验）一律提示由有资质机构出具结论。
- 首采的尽调信息可能涉及供应商商业信息，仅在本轮分析中使用。
