# 03 · 到货验收与差异处置

## 一、时限是第一关（先算这个）

**到货差异处置的第一步永远是：离异议期满还有几天。**

合同通常把期限分成两类，时限完全不同：

| 类型 | 覆盖范围 | 常见期限 | 起算点 |
|---|---|---|---|
| **外观与数量** | 数量短溢、包装破损、明显外观缺陷、规格可见不符 | 当场 / 到货后 3–7 日 | 到货签收日 |
| **内在质量** | 需检验或使用才能发现的（成分、性能、隐藏缺陷） | 到货后 15–30 日，或按约定 | 到货日 / 验收日 |

**合同没约定怎么办**：没有约定的情况很被动，通常只能依法律规定在"合理期限"内主张，且举证更难。此时应立即书面通知并保留所有证据，同时提示用户后续合同必须补上明确期限。

**隐蔽瑕疵的特别提示**：有些质量问题要使用一段时间才暴露（如材料耐久性、设备早期故障）。若合同只写了"到货后 7 日"，理论上过期即视为合格。预处理办法：① 在异议期内书面提出"保留对内在质量的进一步异议权"；② 若有质保期约定，则质保期内仍可主张（质保与异议是两个概念，别混）。

## 二、差异五种类型与处置

### 1. 数量差异（短装 / 溢装）

| 情形 | 处置要点 |
|---|---|
| 散装、计重货物 | **以磅单为准**（我方磅单 vs 对方磅单，差异大时复磅）。合同约定溢短装比例（常见 ±3%~5%）的，比例内按实结算，超比例部分协商处理 |
| 计件货物 | 当场清点，双方签认。短装要求限期补足，或按单价退款 |
| 溢装 | 不能默认接受（占用资金与库存）。按合同约定处理；未约定的，可拒收超出部分或协商按优惠价接收 |

**注意**：短装常与运输损耗混淆。**运输损耗的责任取决于贸易术语**——到厂价（供方承担运输）的损耗由供方担；出厂价（我方自提）的损耗需看谁安排运输。签约时没写清贸易术语的，这一步会扯不清。

### 2. 质量不合格

处置顺序（**不要跳步**）：

1. **立即停止使用并隔离**，做好标识，防止误投料误发货
2. **书面通知**（不要只打电话），附照片与初步数据
3. **取样留存**：保留原样、封样，双方可复检；单方取样易被质疑
4. **要求书面回复**：请在 X 日内给出处置意见
5. **协商方案**：退货 / 换货 / 降价接收 / 返工，各方案的费用与时限写清

**红线：不得擅自处置不合格品**。除为防止损失扩大（如变质、危险品需紧急处理）外，退货、变卖、报废都要先通知对方。擅自处置可能导致丧失索赔权，甚至被反诉。

### 3. 包装破损

- **到货当场拍照**，含破損部位、总体、运输车号、签收单据一并入框
- 区分**内装物是否受损**：包装破损但内装完好，通常只需记录并索赔包装价值或要求改进包装；内装受损则按质量异常处理
- 涉及运输方责任的，**收货时就要在运单上批注异议**，事后补批注通常无效
- 保险理赔需要的材料通常包括：运单、磅单、照片、情况说明、损失清单——事后再收集往往来不及

### 4. 错发 / 规格不符

- 先确认是**发错**还是**我方下错**——两者的责任与费用承担完全不同
- 发错：由供方承担往返运费并限期补发正确货物
- **严禁擅自使用不符规格的物料**，尤其是在危化品、承压件、安全相关物资上——使用后会同时丧失索赔权并引入安全风险

### 5. 单据不齐

常见缺失：材质证明、质检报告、合格证、装箱单、运输资质、危化品随车单证。

- **危化品尤其严格**：随车单证、运输资质、押运要求缺一不可，缺失应拒收或暂存待补，不得先入库
- 单据缺失影响：无法完成入库、无法追溯、影响后续复检与追责
- 处置：书面列出缺失清单，限期补齐；未补齐前货款暂不结算（需与合同付款条件对齐，避免我方违约）

## 三、签收环节的关键动作

**签收单上绝不能出现"验收合格"字样**，除非确实已完成全部验收。

| 应写 | 不应写 |
|---|---|
| "已收货，数量外观待核" | "验收合格" |
| "已签收，内在质量待检验" | "质量无异议" |
| "数量待复磅" | "数量无误" |

签收只代表**货物已交付**，不代表**质量已认可**。一句"验收合格"可能直接放弃后续全部质量主张权。**给收货/仓管岗位的人交代清楚这一点，比事后打官司有用得多。**

## 四、处置留证清单

按发生场景勾选，缺一项就补一项：

- [ ] 合同 / 订单（约定交期、质量标准、异议期、溢短装、贸易术语）
- [ ] 发货单 / 装箱单 / 运单 / 磅单（原始件或清晰照片）
- [ ] 到货签收单（注意有无"验收合格"字样）
- [ ] 现场照片（破损部位、总体、标签批次、车号）
- [ ] 检验报告 / 化验单（自行检验的注明方法与标准）
- [ ] 封存样品（含取样时间、地点、双方签字）
- [ ] 书面通知记录（发出时间、方式、对方接收人）
- [ ] 沟通记录（微信/邮件截图，含时间戳）
- [ ] 损失证明（停线记录、替代采购价差、返工费用、客户索赔）
- [ ] 复检/第三方检测报告（争议较大时）

## 五、处置决策速查

| 现场情况 | 立即动作 | 后续动作 |
|---|---|---|
| 数量短装，比例内 | 按实签收 | 按合同约定结算 |
| 数量短装，超比例 | 拍照留证，暂缓签收或注明异议 | 限期补足或退款，评估逾期责任 |
| 明显质量问题 | 隔离、停用、拍照 | 书面通知 + 取样留存 + 要求处置意见 |
| 隐蔽质量问题 | 记录使用条件与时间 | 异议期内书面提出并保留进一步异议权 |
| 包装破损内装完好 | 拍照、运单批注 | 要求改进包装，索赔包装价值 |
| 包装破损内装受损 | 拍照、运单批注、拒收或暂存 | 按质量异常处理，同步联系保险 |
| 错发/规格不符 | 停用、隔离、不得投产 | 确认责任，限期换货 |
| 单据不齐（危化品） | 拒收或暂存待补 | 限期补齐，未补齐不结算 |
