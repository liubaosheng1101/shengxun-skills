# 02 · 催货升级路径

## 一、先分清：对方是"不想做"还是"做不了"

这是催货的第一个判断，判断错了，后面所有动作都白费：

| 类型 | 典型信号 | 本质 | 有效手段 |
|---|---|---|---|
| **不想做** | 含糊其辞、反复改口、不接电话、报价时就不情愿 | 这单利润低 / 产能被别家占 / 想逼你加价 | **施压 + 给利益**（后续订单承诺、加价换优先、缩短账期） |
| **做不了** | 明确说卡在哪（原料没到、设备坏、资质没下来） | 客观受限 | **协助 + 备选**（帮忙协调、给时间但设上限、同步启动二供） |

**判别方法**：直接问"卡在哪个环节、需要什么条件能解决"。
- 能说清具体环节、给得出条件 → 偏"做不了"，可协商
- 说不清、绕着走、只重复"尽快" → 偏"不想做"，要施压

## 二、三级升级路径

**核心原则：每次升级都要带新东西**（新的证据、新的后果、新的方案）。只是换个更高级别的人重复同样的话，没有任何作用，反而暴露你没有筹码。

### 一级：对接业务员

- **适用**：黄灯初期，尚未逾期，或逾期在 1–3 天内
- **方式**：以沟通推进为主，但**必须留痕**（邮件/微信文字，不要只用电话）
- **说清三件事**：① 合同号与约定交期 ② 我方现在需要的时间 ③ 请对方给出明确答复时间
- **要点**：语气正常，但要写下来。"口头答应"在后续追责时没有证明力

### 二级：销售经理 / 公司层面

- **适用**：一级催办 2 次无实质进展；或已逾期；或对方提出无法接受的交期
- **方式**：书面函件（见 `06-correspondence.md`），抄送对方上一级
- **说清三件事**：① 完整时间轴（约定交期 → 历次承诺 → 今日）② 我方实际损失或将产生的影响 ③ **合同逾期条款的实际后果**
- **关键**：这一级要**明确后果**，但不能把话说死——要给对方留出执行台阶

### 三级：双方高层 / 最后通牒

- **适用**：已严重影响生产；或对方连续跳票；或需要立即启用备选/取消订单
- **方式**：正式函件 + 高层直接沟通
- **说清三件事**：① 最后期限（精确到日）② 到期未达成的处置（取消订单 / 索赔 / 暂停合作 / 列入不合格）③ 保留权利声明
- **要点**：发出前先确认自己真的会执行——**不能执行的威胁，说一次就再也没用了**

## 三、交涉中可用的筹码（按强度排序）

| 筹码 | 强度 | 使用注意 |
|---|---|---|
| **后续订单 / 年度份额** | 强 | 对方最在意。适用于长期合作供应商，需确认自己有权承诺 |
| **付款条件调整**（缩短账期、部分预付） | 中强 | 换交期优先。注意资金风险，别为了赶货变成全额预付 |
| **价格补偿**（赶工费、加急费） | 中 | 谨慎使用。要对方先说数，且金额与紧迫度匹配 |
| **合同逾期条款** | 中 | 有明确违约金条款时有效；没有条款时威慑力有限 |
| **同行信息**（对方知道你在问别家） | 中 | 点到为止，说太细会变成纯粹施压，对方可能直接放弃 |
| **质量/交付记录评级** | 中弱 | 对在意长期合作的供应商有效 |
| **法律途径** | 强但慎用 | 只在金额大、证据全、关系已无维护价值时提；提了不执行会失去全部信用 |

## 四、可供对方选择的台阶

只提要求不给台阶，对方容易"躺平"。主动给出可执行的选项，往往比施压更快拿到货：

| 台阶 | 适用情形 | 我方要拿到什么 |
|---|---|---|
| **部分先发** | 对方有部分成品或半成品 | 先发能发的量，剩余约定期限；运费分担写清 |
| **分批交付** | 一次性赶不出来 | 每批的明确数量与日期，逾期同样适用违约金 |
| **替换同类规格** | 我方产线可接受 | 规格差异书面确认 + 价格调整 + 验收标准 |
| **对方承担加急运费** | 交期已紧但可赶出 | 加急方式与费用由对方承担，写进书面确认 |
| **延后交期 + 补偿** | 确实做不了的客观受限 | 新的明确日期 + 价格或其他补偿 + 若再逾期则升级条款 |

**每个台阶都要落到书面上**，包括数量、日期、费用承担。口头协商的"部分先发"经常变成"什么都没发"。

## 五、催货的三个禁忌

1. **不要只问"什么时候能好"**——这是最没用的问题，对方可以无限重复"尽快"。要问："现在卡在哪一步？需要什么条件能解决？给我一个具体日期。"
2. **不要在第一次沟通就提索赔**——那会让对方把精力转到"免责"上，而不是"赶货"上。先保交付，交付无望再谈追责。
3. **不要越过一级直接找老板**——关系破坏后，一级对接人会消极应对，反而更难拿到真实信息。除非确实需要制造压力，否则按级升。

## 六、升级动作检查表

发出升级动作前，逐项确认：

- [ ] 时间轴完整（约定交期、历次承诺、今日日期、逾期天数）都有书面记录
- [ ] 本次升级带了**新东西**（新证据 / 新后果 / 新方案），不是重复上次的话
- [ ] 后果说明具体且可执行（不说"我们会追究责任"，要说"将按合同第 X 条主张逾期违约金"）
- [ ] 给了对方明确的答复时限
- [ ] 给了至少一条可执行的台阶
- [ ] 同步启动了备选方案（不等对方，自己先有底）
- [ ] 内部已同步（仓储、生产、计划知道可能的延期及影响）
