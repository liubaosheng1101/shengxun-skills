# 01 · 选题判断

选题决定上限。稿子写得再好，选题错了也没有量。

## 一、选题四问（逐条过，任一不过就换角度）

| # | 问题 | 不过关的表现 |
|---|---|---|
| 1 | **受众真的会遇到这件事吗？** | 讲的是"理论上有价值"的事，不是"当下正卡着"的事 |
| 2 | **能不能一句话说清？** | 说了三句还没讲清要讲什么——观众早划走了 |
| 3 | **你有没有一手材料？** | 只能复述别人的观点，拿不出案例、数据、步骤或踩坑 |
| 4 | **和往期能不能形成系列？** | 每条都是孤立的，账号没有积累感 |

**第 3 条最关键。** 知识类口播的护城河是**一手经验**，不是表达技巧——同样的技巧，讲自己踩过的坑比转述别人的结论可信得多。

## 二、系列化：让单条变成资产

每条选题都应有**系列归属与编号**，页眉或封面上体现出来。

```
<系列名> · 第 N 讲
```

好处：

- 观众看到第 N 讲会去找第 1 讲 → 连带播放
- 你自己排选题时，容易发现"哪一块还没讲"
- 一年下来，系列本身就是可复用的资产（合集、专栏、书）

**做法**：维护一份选题清单（讲次 / 主题 / 一句话卖点 / 发布时间），新选题先查清单，避免重复、发现缺口。

## 三、信息增量的四个来源

每一段都必须落到下面四种之一：

| 来源 | 例 |
|---|---|
| **案例** | 具体发生过的一件事（模糊化处理过的真实经历最好） |
| **数据** | 具体数字、比例、金额、时间 |
| **动作步骤** | 第一步做什么、第二步做什么 |
| **取舍理由** | 为什么选 A 不选 B，代价是什么 |

⛔ **禁止的写法**：把一句话换个说法再说一遍、堆形容词、只讲"很重要""要注意"。

**自检句**：把这段删掉，观众会少知道什么？**答不出来就删。**

## 四、从往期里找选题

三个高效来源：

1. **自己踩过的坑**——每一个踩坑都是一条选题（且天然有案例）
2. **被问过的问题**——同一个问题被问第二次，就值得做一条
3. **系列里的缺口**——清单上哪一讲还空着

## 五、动手前先确认

⚠️ **先把选题说清楚再写稿。**

明确这三件事再往下走：

- **讲什么**（一句话卖点）
- **给谁看**（受众的具体处境，不是"所有做这行的人"）
- **看完拿走什么**（一个可执行的动作，或一个纠正过来的认知）

三件事说不清，稿子一定散。

## 六、选题自检

- [ ] 选题四问全过
- [ ] 有一手材料（案例 / 数据 / 步骤 / 取舍）
- [ ] 能挂进某个系列，且有编号
- [ ] 与往期清单比对过，不重复
- [ ] 一句话卖点写出来了
- [ ] 说清了"看完拿走什么"
