# 03 · 口播稿写法

## 一、开头 5 秒：唯一不能含糊的地方

大部分划走发生在开头几秒。**这一段是硬指标，不是风格偏好。**

| 要求 | 说明 |
|---|---|
| **第 0 秒就开口** | 不留白、不出 Logo、不铺垫 |
| **首句是数字或结论** | 不要"今天我们来聊聊…" |
| **首句 ≤2.5 秒** | 约 10 个字以内 |
| **无缓冲词** | 删掉"大家好""其实""那么""说到这个" |
| **单条 ≤100 秒** | 超了就拆 |

### 无效开场（见到就删）

| 无效开场 | 为什么失效 |
|---|---|
| "大家好，我是XX" | 观众不是来找你的，是来找答案的 |
| "今天我们来聊聊……" | 没给任何信息，等于把观众往外推 |
| "最近有很多人问我" | 与观众无关的社交铺垫 |
| 从背景、历史、定义讲起 | 解药在后半段，观众等不到 |
| 先卖关子（"最后一点最重要"） | 前几秒没有实质信息，撑不住 |

### 可用的开场型

| 型 | 做法 | 例 |
|---|---|---|
| **结论前置** | 直接给结论 | "报价单上最贵的不是价钱，是那三行附加费。" |
| **数字前置** | 用具体数字制造信息量 | "同一个东西，三家报价差 40%，差的不是质量。" |
| **冲突前置** | 直接给矛盾 | "你比完价选了最便宜的，结果年底一算反而贵了。" |
| **纠错前置** | 指向一个常见错误 | "大多数人对这个数字的理解都是错的。" |

## 二、口语化：写"能念出来的句子"

| 原则 | 好 | 差 |
|---|---|---|
| 一句话一个信息 | 拆成两句 | 一句话塞两个矛盾 |
| 用短句 | "先看单价。" | "首要考虑的因素应当是单价水平。" |
| 用口语词 | "贵了""砍价""坑" | "成本偏高""商务谈判""风险敞口" |
| 不用书面连接词 | "所以""但是" | "综上所述""基于此""进而" |
| 留半句给对方 | 说一半，让观众接 | 每句都答满，没有回味 |

⛔ **不念设定。** 不要用一段话介绍背景、来历、行业常识——这些要么用一句带过，要么直接不要。

## 三、时长估算：先算再写

**中文正常语速约 4.2 字/秒**（口播）。这是估算基准。

```
目标 95 秒 → 约 400 字
目标 60 秒 → 约 250 字
```

**做法**：写完先算总数，再逐段核对——哪一段超了就删，哪一段空了就补案例。

**各段的合理字数**：

| 段落 | 秒 | 字 |
|---|---|---|
| 钩子 | 5 | ≈ 20 |
| 单个要点 | 12–18 | ≈ 50–75 |
| 收尾 | 10 | ≈ 40 |

## 四、语速校准：先改文案，不要硬变速

⚠️ **时长对不上时，优先扩写或精简文案，不要靠变速硬凑。**

**为什么**：变速幅度一旦明显偏离正常，听感就会不对劲——要么拖沓，要么赶拍，两种都伤完播。

**判据**：

| 变速后的听感 | 结论 |
|---|---|
| 接近正常语速 | ✅ 自然 |
| 明显偏慢（拖沓、字与字黏） | ❌ 文案太短，应**扩写** |
| 明显偏快（赶拍、换气不够） | ❌ 文案太长，应**精简** |

**经验区间**：整体变速倍率控制在 **0.75–1.55** 之间；越接近 1.0 越好。偏出这个区间说明文案本身的量就不对。

## 五、拆条规则

单条超过 **100 秒**就拆：

- 拆点选在**两段之间**（不要拆在要点中间）
- 拆出来的上集要有独立的收尾，不能话说一半
- 拆出来的下集要有独立的钩子，不能"接着上集讲"
- 两条分别挂各自的系列编号

## 六、文案与字幕的一致性

⚠️ **字幕文本一律取脚本原文。**

**语音转写只用来给时间，绝不能拿转写文本当字幕。** 转写会把专业词听错——实测「报价单」被听成「暴甲单」、「供应商」被听成「公应商」，专业人设直接砸。

**正确做法**：

```
文本 ← 脚本原文（一个字不改）
时间 ← 语音转写（或多个变体交叉验证）
```

**推论**：写脚本时就要意识到**这段文字最终会逐字出现在字幕上**——所以别写"这个那个""就是说"这类口语填充词，它们在字幕里特别刺眼。

## 七、口播稿自检

- [ ] 第 0 秒就开口，无留白与 Logo
- [ ] 首句是数字或结论，≤2.5 秒
- [ ] 无"大家好""今天聊""其实"等缓冲词
- [ ] 每句话都能顺口念出来（念一遍，卡的地方就是要改的地方）
- [ ] 字数与目标秒数能对上（4.2 字/秒）
- [ ] 无书面连接词与行业套话
- [ ] 没有用旁白念设定
- [ ] 单条 ≤100 秒，超了已拆条
- [ ] 全文没有会出现在字幕里显得刺眼的填充词
