# 04 · 发布文案与合规

## 一、发布文案四要素（缺一不可）

| 要素 | 作用 | 要求 |
|---|---|---|
| **正文** | 视频内容的文字版补充 | 3–6 行，把视频结论复述成可读的文字，不要只写"看视频" |
| **话题标签** | 帮助被找到 | 3–6 个，1–2 个大词 + 2–4 个精准词 |
| **建议封面标题** | 站外/信息流展示 | ≤12 字，含数字或反差 |
| **AI 声明** | 合规 | 明确写出内容由 AI 生成 |

## 二、正文怎么写

**把它当成"给没看视频的人看的信息摘要"**，而不是视频文案的复制。

结构：

```
第一行：核心结论（一句话）
第二到四行：三个要点（每行一个，可读可存）
最后一行：引导（一个动作）
```

**要点**：

- 第一行必须是结论，不要"大家好"开头
- 每行独立成立——观众扫一眼就能拿到信息
- 不要写"详见视频""看我上一条"
- 涉及具体操作时，把步骤列成短行

## 三、标签怎么选

| 类型 | 数量 | 例 |
|---|---|---|
| 大词（领域词） | 1–2 个 | 行业相关的通用词 |
| 精准词（细分） | 2–4 个 | 具体场景/方法/岗位 |
| 系列词 | 1 个 | 你的系列名 |

⛔ **不要堆无关热词。** 标签与内容不匹配，会被判低质，也会引来不相关的观众（完播率更差）。

## 四、封面标题怎么写

**≤12 字，必须含数字或反差。**

| 好 | 差 |
|---|---|
| 报价差 40% 的真相 | 浅谈采购成本控制 |
| 我砍价砍错了三年 | 采购谈判技巧分享 |
| 这三行字最贵 | 论报价单的重要性 |

**规则**：

- 用**具体**的词，不用抽象名词
- 制造反差或悬念，但**不能与内容不符**（标题党会掉信任）
- 不要把整句口播塞进封面

## 五、AI 声明（硬要求）

- 内容由 AI 生成时必须明确声明
- 声明放在**正文里**，不要藏在末尾小字
- 有明确的标识要求时，视频画面内也要有（标识时长一般要求 ≥3 秒、出现在前 5 秒内、居中不遮挡主体）

## 六、内容红线（逐条过）

- [ ] 无极限词（"最""第一""国家级""唯一""绝对"）
- [ ] 无诱导性表述（"不转不是…""点击领钱"）
- [ ] 无编造的法律条文、法规编号
- [ ] 无编造的数据与研究结论
- [ ] 不涉封建迷信，不承诺"实际效果"
- [ ] 医疗、金融、投资类**不做效果承诺**（需资质）
- [ ] 不使用真人明星姓名或肖像暗示
- [ ] 不涉及可识别的具体企业负面指名（用"某供应商"这类模糊表述）

## 七、发布前检查

- [ ] 四要素齐全
- [ ] 正文第一行是结论
- [ ] 标签与内容匹配，未堆无关热词
- [ ] 封面标题 ≤12 字，含数字或反差，且与内容一致
- [ ] AI 声明已写
- [ ] 六节红线全部通过
- [ ] 正文、封面、口播稿三处口径一致（不要正文说的和视频里说的不一样）
