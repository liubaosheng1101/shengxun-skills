# 03 · 风格验收与探针

**核心结论：参考图的风格 = 生成它的提示词的风格。**

同一套视频提示词下，换成卡通向的参考图就出卡通片；换成超写实柔光的参考图就出实拍感。所以参考图必须按**风格**验收，而不是按"像不像那个人"验收——"像"是次要的，"风格对齐"才是决定成片质感的那个变量。

## 一、为什么不能靠眼睛判断

参考图之间风格差异往往是**亮度、饱和度、锐度**的细微偏移，人眼在单张图上很难判断"这张比基准更艳还是更锐"。需要的是**可复现的数值**。

## 二、四角背景探针

**取图四角各 16% 边长的纯背景块**，量三项背景指标，外加一项全图指标：

| 指标 | 量什么 | 跑偏的表现 |
|---|---|---|
| 背景亮度 | 四角块的亮度均值 | 数值**下降** → 背景变暗，往闷/暗调走 |
| 背景饱和度 | 四角块的饱和度均值 | 数值**上升** → 背景变艳，往广告/插画走 |
| 背景锐度 | 四角块的锐度均值 | 数值**大幅上升** → 背景纹理变多，胶片感被削 |
| 全图锐度 | 整图锐度 | **偏离基准最多的一项**，最常用来挑图 |

**影棚浅灰 + 柔光**的稿子，这几项会稳定在一个窄区间。一旦背景变暗/变艳/变锐，就是风格跑偏。

**前提**：基准图的背景必须是干净的影棚背景。背景里自带场景（街景、室内陈设）的图不适合当基准。

## 三、实测对照（同一基线下）

| 参考图 | 背景亮度 | 背景饱和 | 背景锐度 | 全图锐度 |
|---|---:|---:|---:|---:|
| **基准（影棚浅灰 + 柔光定稿）** | 183.4 | 44.7 | 584 | 653 |
| 同骨架变体（可用） | 144.7 | 35.6 | 724 | 703 |
| 同骨架变体（更接近） | — | — | — | 587 |
| 暗调变体（**淘汰**） | 108.9 | 67.2 | 2280 | 1290 |
| 反写实旧稿（**淘汰**） | 198.0 | 24.2 | 365 | 720 |
| 暗背景单视图稿（**废图**） | 21.1 | 182.4 | 7.6 | 94.3 |

读法：

- 淘汰的那两张，一张**背景亮度掉到 109、饱和度飙到 67、锐度飙到 2280**（明显往暗调高饱和走了），另一张虽然亮度看着正常，但**锐度只有 365**（画面软塌）。
- 最后一行是**废图判据**：全图锐度只有 94（基准 653）——等于一张近乎全暗、几乎没有细节的图，连测都不用测。

## 四、挑图口径

**以全图锐度最接近基准的那张为首选。**

同骨架生成的多张候选，风格差异主要体现在这一项上。实测选中的候选，探针值通常落在基准的 ±20% 区间内；偏离 1.5 倍以上的基本可以淘汰。

> ⚠️ 探针是**筛选工具，不是终审**。它负责把明显跑偏的筛掉、把接近的排个序；最终采用哪张，仍以人的判断为准（尤其涉及面部好不好看这种探针测不出的东西）。

## 五、反写实词：风格跑偏的最大来源

生成定稿图时，以下这类词会把风格**从写实推向卡通/插画**，是"出片偏卡通"的头号真因：

```
premium stylized 3D render
smooth idealized skin texture without pore detail     ← 去毛孔 = 磨皮
soft cel-shaded volumetric lighting
NOT photorealistic / NOT photograph / not a real person / digital CG character
```

**写实向的骨架长这样**（影棚感、柔光、不写反写实词）：

```
hyperrealistic CG character
soft digital skin, subtle skin texture
light gray studio background, fashion lookbook style, soft cinematic lighting
```

⚠️ 一个真实教训：同一批设定里，有的稿用了上面第一组（反写实），有的用了第二组（写实）。**用第一组出的图当参考图，成片必然卡通**——不是张数、不是模型版本、不是补词的问题，就是参考图的风格取向。

## 六、否定词墙救不了风格

把 `NOT cartoon, NOT flat animation, NOT anime, NOT 3D animated film, NOT cel-shaded …` 一长串写进**视频提示词**，指望压住卡通——**无效**：

1. 模型的失败模式是**忽略正文否定句，甚至反解**（写了 NOT cartoon 反而更卡通）。
2. 这串否定词与风格串里的 CG 向描述**自相矛盾**（同时下两个相反指令）。

**正确做法**：风格问题在**参考图那一层**解决（换写实定稿），不在视频提示词的否定词里解决。

字幕/文字类否定词（`no subtitles`、`no text overlay` 等）是**功能性**的，要保留——去掉后模型可能把台词烧成画面字幕。这两类否定词要分开对待。

## 七、验收清单

- [ ] 背景是干净的影棚背景（能取到四角纯背景块）
- [ ] 四角背景亮度/饱和度/锐度落在基准窄区间内
- [ ] 全图锐度与基准偏差在可接受范围（明显偏离 >1.5 倍即淘汰）
- [ ] 生成提示词里**没有**反写实词
- [ ] 全图锐度未低到"废图"水平（远低于基准说明画面近乎全暗/无细节）
- [ ] 风格确认后才进入面部质量的人工判断
