# 05 · 一致性巡检与验证

## 一、过审判定：只能靠视频端试跑

**判断一张参考图能否进入管线，只能用视频端最低档试跑。**

| 端点 | 同一张（会被拦的）图的结果 |
|---|---|
| **视频端**（图生视频） | ❌ 被拦，报内容安全错误，报文指向"参考图"位置 |
| **图生图端**（生图模型） | ✅ **照常出图** |

**结论：两个端点的内容审核标准不共用，图生图通过 ≠ 视频端能过。**

所以：

- 想省钱的"廉价探针"（用便宜的生图接口代替视频试跑）**已被证伪**——拿已知会被视频端拦下的图去跑生图，居然通过了。
- **正确做法**：视频端 4 秒最低档试跑。**通过才收费，被拦免费**——这是成本最低的可行验证方式。
- 每通过一张，就把"已过审"记进这张图的元信息；被拦的记入黑名单。

## 二、拦点判定：看"来源链"，不看别的

**决定过不过的，是投喂给视频的那张图的来源链：**

| 来源链 | 结果 |
|---|---|
| **文生图产物**（凭空生成，无参考图） | ✅ 通过 |
| **图生图派生物**（派生自任意一张参考图/定稿） | ❌ 被拦 |

实测证据（同一批实验，报错逐字相同）：

| 投喂的图 | 结果 |
|---|---|
| 文生图凭空生成（写实措辞） | ✅ 过 |
| 四联设定图**本身**（定稿口径） | ❌ 拦 |
| 四联设定图，改成纯 CG 风格口径 | ❌ 同一条报错 |
| 图生图自四联图派生的单人大头贴 | ❌ 同一条报错 |

**判定与提示词用词无关，与图的版式无关，与渲染口径也无关。**

**推论**：**"用反写实词压制"这条路走不通。** 图生图是"图像到图像"的身份迁移，写实度由参考图决定，文字层面的反写实词压不过它。实测从轻到重三档剂量（加 `not a real person` → 再加 `stylized 3D render` + 去毛孔 → 再加 `cel-shaded` + 全否定墙）**全部被拦**。

**也不要再在这条路上试别的措辞变体**——那属于重复试错。

## 三、风格与过审是两件独立的事

| 手段 | 影响生成一致性 | 影响过审 |
|---|---|---|
| 四联图 / 三视图拼图 | ✅ 有改善 | ❌ **无关** |
| 反写实词剂量 | ✅ 有影响 | ❌ 无关 |
| 图片版式 | ✅ 有影响 | ❌ 无关 |
| **来源链**（文生图 / 图生图） | — | ✅ **决定性的** |

这个区分很重要：有人以为"换成拼图版式就能过审"，实测证明拼图形态的四联图**只要它是图生图产物，照样被拦**。**版式只是来源链的代理指标，不是原因。**

## 四、三人以上与远景的一致性：四联图

**问题**：三视图在近景/特写有效，但**远景 / 全身 / 多人同框时脸仍会崩**——脸在画面里占比小，模型缺少约束就自由发挥。

**技巧 · 四联角色图（横构图）**：

- **左侧** = **无头**全身三视图（正面/侧面/背面，**颈部以上去掉头与头发，切口干净**）→ 锁身材/服装/鞋
- **右侧** = 完整**正脸特写** → 锁五官/妆容

**为什么要去头**：三视图每张都有脸，保留就会在 3–4 张脸之间**做平均** → 更糊。去头后，脸的唯一来源是右侧那张特写，约束唯一。

**验收口径：人脸检测结果 = 1 张**（左侧 0 + 右侧 1）。≥2 说明去头失败，需重做。

## 五、状态/装饰变化：必须派生，不能只写描述

角色有**可见状态变化**时（创可贴、伤妆、湿身、换装），**必须以已有参考图为基准再派生一张**，不能只在视频提示词里描述。

原因：只在提示词里描述，视频模型会**每镜自由发挥位置/大小**，跨镜不统一。

⚠️ 装饰若在同一集内演进（渗血 → 结痂），**每个状态各需一张**。

## 六、巡检方法：对比页四模式

多版本素材人眼比对时，用对比页，四种模式：

| 模式 | 用法 | 适用 |
|---|---|---|
| 并排 | 两张左右放 | 快速看差异 |
| **闪烁** | 同一位置交替显示 | **最容易看出人脸差异**——推荐用于角色一致性比对 |
| 叠加 | 半透明叠在一起 | 看整体轮廓偏移 |
| 差值 | 逐像素相减 | 量化差异 |

**为什么推荐闪烁**：两张脸分开看时人眼会觉得"都挺像"，快速交替时差异会立刻跳出来。

## 七、定位被拦/异常的镜

整集级别的巡检，需要先**逐镜切分**再比对：

- 用场景切变把整集切成**镜头**（处理单元必须是镜头，才能整镜判断与替换）。
- ⚠️ 检测前先把画面**缩小**（例如缩到 270×480 再检测），否则高分辨率素材慢到不能忍。
- ⚠️ 切变阈值需要调：太低会把镜头内的小变化也切开，太高会漏（同场景相邻镜差异小）。

## 八、交付前的一致性自检

- [ ] 引用表里所有参考图路径存在
- [ ] 无「非定稿」图被引用
- [ ] 黑名单与当前文件名一致
- [ ] 本批参考图已快照
- [ ] 每个角色的镜**来源链统一**（不要一部分用文生图定稿、一部分用图生图派生）
- [ ] 该角色在**全部出场镜**里用的是**同一张**定稿（换版必须成批重出，否则同角色跨集换脸）
- [ ] 远景/全身/多人镜已用四联图
- [ ] 状态装饰变化已派生对应参考图
- [ ] 对比页（闪烁模式）抽查主要角色，确认无脸型漂移
