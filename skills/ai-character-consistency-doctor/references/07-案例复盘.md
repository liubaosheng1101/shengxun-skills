# 07 · 案例复盘

五个真实排错过程。**重点不是结论，而是"怎么定位到那一层的"**——把当时的错误方向也写出来，因为那些方向最容易被重新走一遍。

---

## 案例一：成片偏卡通，查了四轮才找到参考图

**症状**：整部剧出片偏卡通、塑料感，不是写实真人质感。

**走过的弯路（全部无效）**：

1. 换更快的模型档位 → 更差，回退
2. 改参考图张数（1 张 / 3 张 / 原图三张 / 脸特写+正背）→ 都不是根因
3. 去掉提示词里的风格补词 → 没回到基准
4. 把锚定句还原成历史备份那版 → 无改善
5. 对比两个版本的分镜手册 → 同一镜提示词**逐字相同**

**真因**：**参考图的风格**。

那批旧参考图的**生成提示词**是反写实取向的：

```
premium stylized 3D render
smooth idealized skin texture without pore detail      ← 去毛孔=磨皮
soft cel-shaded volumetric lighting
NOT photorealistic, NOT photograph, not a real person, digital CG character
```

而新定稿用的是：

```
hyperrealistic CG character
soft digital skin, subtle skin texture
light gray studio background, fashion lookbook style, soft cinematic lighting
```

**没有任何反写实词**。

**关键认知**：**参考图的风格 = 生成它的提示词的风格。** 同一套视频提示词下，换卡通向的参考图就出卡通片。所以参考图要按**风格**验收，不是按"像不像"。

**附带发现**：另一张旧图还多了一跳——它是"从 A 服装三视图再图生图派生出 B 服装"的**两跳派生**。经验规律是"一张图不要反复整张过模型，两次之后脸会变对称、变塑料"，两跳派生正是它最卡通的原因之一。

**沉淀的方法**：四角背景探针（见 `03`）。

## 案例二："疑似真人"被拦，根因不是措辞

**症状**：参考图投进视频模型时被判"疑似真人"拦下。

**走过的弯路**：以为是提示词措辞太写实，于是加反写实词，**从轻到重三档剂量**递进试——全部被拦，且**报错逐字相同**。为此花了一轮预算去"摸剂量曲线"，结论是这个方向根本不存在。

**真因**：**投喂给视频的那张图的来源链**。

- 那张被拦的图，是**图生图自真人照片**产出的 → 继承了写实度 → 判真人。
- 另一张能通过的图，是**文生图**凭空生成的 → 过。

**验证过程**（这部分方法论价值最高）：

1. 先做了个"廉价探针"的设想——用便宜的生图接口代替视频试跑判断能否过审。
2. **自检直接否掉**：拿**已知会被视频端拦下**的那张图去跑生图接口，**居然通过了**。
3. 结论：**两个端点的内容审核标准不共用**，生图端通过 ≠ 视频端能过。判断只能靠视频端试跑。

**另一条弯路**：以为换成"四联图/拼图"版式就能过。实测：四联图当参考图，报的是与单人大头贴**一模一样的错**。**版式只影响生成一致性，不影响过审——这是两件独立的事。**

**最终解法**：定稿一律走**文生图**。

## 案例三：年龄不符，前面几轮一直在改错地方

**症状**：某老年角色出片年龄偏轻，皱纹/老态不够。

**走过的弯路**：反复调参考图（换基准图、加皱纹词、迭代了六七个版本），部分版本过了审，但年龄感仍不达标。

**真因**：**视频提示词里明写了"中年"**，与定稿锚定句里的 `elderly … late 60s` **互相抵消**。文字层压过参考图。

**处置**：
1. 剥掉提示词那一侧的年龄词（`strip_conflicting_age`）。
2. 补该角色的写实锚——**只描述真人质感与年龄痕迹**（皱纹、皮肤松弛、老年斑），不加任何风格词。

两者加上后，相关镜头**全部过审，年龄也达标**。

**关键认知**：**"年龄不符"的根因在提示词冲突，不在参考图，比参考图影响大得多。**

> 附带教训：定稿通用词里的"磨皮"向描述（`smooth idealized skin`）会把这些年龄痕迹磨平。
> 那句是为年轻角色调的，**不能用在老年角色上**。

## 案例四：同一角色，有的镜真、有的镜假

**症状**：同一个角色，一部分镜头真人感达标，另一部分明显飘、像另一个人。

**定位过程**：全量审计角色描述，发现分镜手册里有个角色在 **8 个镜头**里都被写到了，但**参考图库里根本没有这个人**。

→ 这 8 个镜一直只挂写实锚、**长相每镜自己飘**。这就是"有的真有的假"的直接原因。

**真因**：**库里缺这个角色的参考图**。

**处置**：补该角色的定稿三视图（文生图 + 写实尾串），并补上：
1. 该角色的写实锚定句
2. 参考图引用表注册
3. **别名**——这个角色的描述常与背景人物同段出现，需要别名才能正确定位到它自己那一段

**关键认知**：**"脸的真实度取决于参考图"。** 没有参考图 = 每镜自由发挥。

> 同类问题还有：手册里同一角色的**年龄写了三个不同值**（不同集数不一致）。
> 处置口径：**以首次登场那集的描述为准**（其余特征各集一致、无冲突时）。

## 案例五：被拦过的旧脸，无法在本管线复用（核心两难）

**症状**：早期在**外部平台**上做完的剧，要迁移到新管线继续做，但已发布集的那张脸用不了。

**两难**：

| 路线 | 与已发布集的人物一致 | 能过审 |
|---|---|---|
| **文生图**重建 | ❌ 五官/发型/服装全变 | ✅ 通过 |
| **图生图**重建（参考旧图） | ✅ 跟旧图走 | ❌ 被拦 |

**根因**：图生图**继承参考图的写实度**。旧图之所以被拦就是因为"像真人"，图生图的产物自然继承同样的写实度 → 同样被拦。

**已证伪的"两头都要"路线**：图生图保住身份 + 用反写实词把产物从"像真人"压成"数字人"。**实测三档剂量全部被拦。**
→ **写实度由参考图决定，文字层面的反写实词压不过它。**

**可行出路只有两条**：

- **A. 换新形象 + 集内统一重出**（该角色在该集的所有镜头全部重出，保证集内一致）
- **B. 该角色的镜头仍走外部平台**（那边能收写实参考图），本管线只做其他角色

**这不是单个角色的问题**：同一批从外部平台迁移过来的角色，**大概率全部会被拦**——做决策时要按"整批角色一起"算账，而不是逐个踩坑。

> 这也是一个重要的**预防性结论**：**新项目一开始就用本管线的口径做定稿图**，
> 不要等做完十几集再迁移——迁移时旧脸基本不可复用，返工量是整部剧。

## 共性提炼

五个案例的根因分别落在**四个不同的层**：

| 层 | 案例 | 一句话 |
|---|---|---|
| **参考图风格** | 案例一 | 风格=生成它的提示词的风格，按风格验收 |
| **参考图来源链** | 案例二、五 | 文生图过、图生图拦；版式与措辞都无关 |
| **提示词冲突** | 案例三 | 年龄词压过参考图，剥掉提示词那一侧 |
| **参考图有无** | 案例四 | 没有参考图 = 每镜自由发挥 |

**排错的关键动作**：先判断症状属于哪一层，**再在那一层改**。四次弯路里有三次是"调错层"。
