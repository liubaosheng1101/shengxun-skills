# 02 · 参考图资产与投喂口径

参考图是角色一致性的**唯一可靠基准**。这一环管理不好，后面所有调参都是在错误的基础上做。

## 一、目录与命名

```
参考图/
├── <角色A>/
│   ├── 【定稿】<角色A>_三视图.png     ← 唯一被引用的文件
│   └── 归档/
│       ├── 历史稿/                    ← 用户原图、未选用稿
│       └── 历史版本/                  ← 被替换下来的旧定稿
├── <角色B>/
│   └── ...
```

规则：

- 角色目录下**只放带「定稿」前缀的图**，其余全部进 `归档/`。
- **不带「定稿」前缀的图一律不引用。** 看到它出现在引用清单里，就是配置错了。
- **换版必须换文件名**——尤其**被拦过的图不要复用同名路径**，否则旧的黑名单条目会误挡新图。
- 角色目录的**上一级不放图**，只放角色目录。

## 二、主动预防：每条参考图都要有"身份"

参考图出问题时，最耗时间的不是修，而是**不知道这张图是哪来的、改过什么**。给每张图留三行元信息：

| 项 | 记什么 | 为什么 |
|---|---|---|
| 来源链 | 文生图 / 图生图（派生自谁） | 直接决定会不会被拦（见 `05`） |
| 生成提示词 | 完整提示词，逐字留档 | 换版时**只改局部、复用其余**的唯一依据 |
| 过审记录 | 在哪个镜验证过、结果如何 | 没验证过的图不能直接进管线 |

> ⚠️ 定稿图一旦丢失而引用表还指着它，管线**不会报错**，只会静默出一批"无参考图脸"。
> **换版或清理参考图之后，务必回头确认引用表要的文件确实存在。**

## 三、投喂口径

1. **每个角色只送 1 张三视图拼图。**
   - 依据：① 单张的"参考图风格"能干净地传递到成片；② 送多张会让模型在多个视角之间做平均，实测比单张更塑料。
   - 演变结论：单张拼图 → 3 张 → 原图三张 → **回到单张**。
2. **单视图（正/侧/背分立图）默认不投喂。** 它们是图生图派生物，是"疑似真人"被拦的高发来源，只留库备用。
3. 无拼图的角色按 正面 → 侧面 → 背面 逐张送，上限 3 张；全镜上限约 9 张。
4. **转向镜**（需要看侧后方的镜头）才补第二张，其余一律单张。
5. **尺寸必须与成片同比例（竖屏剧 = 9:16）。** 参考图的宽高比 = 成片宽高比；横构图定稿即使过审，也会出横画面进不了竖屏剧。

## 四、候选转正（三步，缺一不可）

新做/重建一张定稿图后：

```
① 生成候选 → 用户选定（或按探针挑）
② 转正为「【定稿】<角色>_三视图.png」（新文件名），旧稿自动进 归档/历史版本/
③ 把新路径注册进参考图引用表 + 同步黑名单条目
```

**漏掉第 ③ 步是最常见的"改了没生效"**——图换了但引用表还指着旧路径。

## 五、黑名单

记录触发过内容安全拦截的图，后续一律不引用。

| 规则 | 说明 |
|---|---|
| 按**文件路径**记 | 因此改名后**必须同步**黑名单条目，否则新文件不受保护 |
| **同名换内容要删旧条目** | 若某张图被重新生成（同名路径换了内容），必须删掉它的黑名单条目，否则新图会被旧条目误挡 |
| 被拦不扣费 | 命中拦截的图可以直接记黑名单，不必反复试 |

## 六、批量提交前：快照

**参考图必须在整批开始前一次性快照。**

原因：某镜失败后会把它的参考图写进黑名单。如果参考图是在**提交时才计算**的，那么同一批里后面用同一张图的镜头，会在这张图被拉黑之后**被静默降级成"无参考图"**——不报错，只是脸开始飘。

## 七、交付前自检

- [ ] 引用表里每个路径都存在（跑一次路径校验）
- [ ] 被引用的图**全部带「定稿」前缀**
- [ ] 黑名单条目与当前文件名一致；同名换内容的条目已清
- [ ] 定稿尺寸与成片同比例
- [ ] 本批参考图已快照
- [ ] 每张定稿图有来源链、提示词、过审记录三项元信息
