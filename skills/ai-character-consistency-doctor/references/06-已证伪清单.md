# 06 · 已证伪清单

**这里每一条都是花过钱、走过弯路得出的结论。看到它们，直接跳过，不要再试。**

## 一、关于"出片偏卡通 / 不够写实"

| 试过的做法 | 结论 |
|---|---|
| 换更快的模型档位想解决"不够仿真" | ❌ 不是模型问题。更快的档位**比默认档更差**，默认档本身能出定稿效果 |
| 改参考图张数（1 张 / 3 张 / 原图三张 / 脸特写+正背） | ❌ 都不是根因 |
| 去掉生成提示词里的风格补词 | ❌ 没有回到基准 |
| 把锚定句还原成历史备份那版 | ❌ 无改善 |
| 检查分镜手册版本差异 | ❌ 两个版本的同一镜提示词**逐字相同** |
| **换参考图的风格（换成写实文生图定稿）** | ✅ **这才是根因** |

## 二、关于"参考图被拦"

| 试过的做法 | 结论 |
|---|---|
| 图生图 + **轻度**反写实 | ❌ 被拦 |
| 图生图 + **中度**反写实（加风格词 + 去毛孔） | ❌ 被拦 |
| 图生图 + **重度**反写实（加 cel-shaded + 全否定墙） | ❌ 被拦，报错与前两档**逐字相同** |
| 把"绝对禁止词"全写进提示词当护栏 | ❌ 无效。平台**不做提示词词表匹配**，把 10 个禁词全写上照样出图 |
| 换成拼图/四联图版式想绕过 | ❌ 版式不解决过审。同样是拼图形态的四联图，只要是图生图产物，**照样被拦** |
| 用便宜的生图接口当"廉价探针"判断能否过审 | ❌ 已被证伪——已知会被视频端拦下的图，生图端居然通过。**两端审核不共用** |
| **换成文生图产物** | ✅ **这才是解法** |

> ⚠️ 「绝对禁止词」表至多只能当**风格控制**手段（避免画面往写实推），**不能当审核护栏**。
> 它本身还与实践矛盾：配角三视图用的写实尾串里就含 `lifelike / realistic human skin`，
> 而这些三视图**从未被拦过**。

## 三、关于"参考图投喂"

| 试过的做法 | 结论 |
|---|---|
| 只给正面参考图 | ❌ 模型拿不到立体信息，脸偏平 → 改为给三视图拼图 |
| 正/侧/背三张单图分开送 | ❌ 拼图更稳；单图只在转向镜补 |
| 每角色送 3 张（拼图 + 侧/背） | ❌ 被拦的全是**单视图**；拼图从未被拦 |
| **每角色只送 1 张三视图拼图** | ✅ 现行口径 |

## 四、关于"年龄 / 人种不符"

| 试过的做法 | 结论 |
|---|---|
| 反复调参考图想修年龄 | ❌ 方向错了。真因是**视频提示词里的年龄词** |
| 用磨皮向的词让老年角色"更干净" | ❌ 会把皱纹/皮肤松弛/老年斑磨平，年龄就读不出来了 |
| 只靠中文行描述人种，转英文时整段丢掉 | ❌ 提示词里没有任何人种限定 → 偏欧美审美的描述会自由发挥成混血脸。**必须显式带人种限定** |

## 五、关于"流程机制"

| 现象 | 结论 |
|---|---|
| 锚定/剥离模块"看起来配好了" | ⚠️ 曾长期**默认关闭**，等于机制全都没生效。**必须确认默认开启** |
| 换了参考图但成片没变化 | ⚠️ 引用表还指着旧路径 → **转正必须三步齐全** |
| 参考图在库里但像没用上 | ⚠️ 路径不存在时**静默返回空**并照跑，不报错。**跑前必须校验路径** |
| 同批靠后的镜头突然脸飘 | ⚠️ 某镜失败后拉黑了参考图，同批后续被静默降级。**必须批量前快照** |
| 黑名单"明明记了却没生效" | ⚠️ 黑名单按路径记，**改名后必须同步**；同名换内容的要删旧条目 |

## 六、成本口径（真实经验）

- 视频生成按秒计费，**重抽不退款**。
- **一次过率按约 60% 估**：实付 ≈ 预估报价 × **1.67**。做预算时要按这个倍数算。
- **被内容安全拦截不扣费**——所以"能不能过审"的试错是低成本的（试跑用最低档秒数）。
- 真正烧钱的是**过审但质量不行**的重抽。
- 参考图候选的生成成本远低于视频（单张参考图 ≈ 1/6 个镜头的视频成本），**在参考图这一层多做候选、多试几轮，比在视频层反复重抽划算得多**。

## 七、一句话总结

> **风格问题在参考图层解决，过审问题在来源链上解决，年龄/人种问题在提示词冲突上解决。**
> 三件事各有各的层，**调错层就是白花钱**。
