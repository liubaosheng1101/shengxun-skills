# 04 · 对账查漏与校验区

台账最怕的不是"记错"，而是**"漏记了但看不出来"**。记错还能改，漏记会让所有汇总**静默变小**——数字看着正常，其实是残缺的。

## 一、核心思路：把"漏记"变成一个能被检查的数字

做法：在应付表底部建一个**校验区**，把"应该有值、但不该有未挂项"的量算出来，**期望值写 0**。

**只要这三项不是 0，就说明有单据没挂上。**

| 校验项 | 期望 | 不为 0 说明什么 |
|---|---|---|
| **未挂合同的到货车数** | **0** | 有到货没登记合同编号 |
| **未挂合同的到货量** | **0** | 同上，按吨算 |
| **未挂合同的付款** | **0** | 有付款没挂合同，预付款归集不到 |

**这三个"0"是整个台账最值钱的三个数字。** 它们把"感觉对得上"变成"机器确认对得上"。

## 二、配套的辅助校验项

为了让上面三项能被解释，还要同时算出分解项：

| 校验项 | 算法 |
|---|---|
| 到货记录总车数 | 车数列求和 |
| 其中：现货到货车数 | 按"现货"标记筛 |
| 已挂合同车数 | 总车数 − 现货车数 |
| 付款记录总额 | 付款表金额求和 |
| 已归集付款 | 付款表里挂了合同的金额求和 |
| **未挂合同付款** | 付款总额 − 已归集付款 |

这样一旦"未挂合同车数 ≠ 0"，你能立刻判断是**现货没标**还是**合同号抄错**。

## 三、查找漏记的标准动作

按这个顺序查，最快：

1. **看校验区**：哪一项不是 0 → 定位到问题类型
2. **筛出未挂项**：把该列空白的行筛出来（车数不为 0 但合同号为空，或付款金额不为 0 但合同号为空）
3. **两种情况分开处理**：
   - **本来就该是现货** → 补标"现货"，不是错
   - **抄漏了合同号** → 回到原始单据核对后补上
4. **补完再看校验区**：回到 0 才算干净

⚠️ **不要为了"让它变成 0"而随便填个合同号。** 归错合同比不归更难查。

## 四、其他必须定期查的项

| 项 | 怎么看 | 异常含义 |
|---|---|---|
| **重复付款** | 同日期同金额同合同出现多次 | 可能是真实的多次付款，也可能是重复录入——**只标注，不自动删** |
| **金额三处不一致** | 到货金额 vs 合同单价 × 吨数 vs 发票金额 | 三个口径本就不一定相等，但差异要有解释 |
| **到货超前于合同** | 累计到货 > 合同量 | 要么合同量填错，要么超发 |
| **付款超前于到货** | 预付远超已到货 | 正常（先款后货）但要看额度是否失控 |
| **长期零到货的在途合同** | 在途未到量 > 0 且超过提前期很多天 | 合同可能要作废或需要催 |
| **供应商名称多种写法** | 同一家被拆成多条 | 汇总失真（见台账清洗类文档的名称归一） |

## 五、日报与账务的交叉验证

**日报里的用量是反推的**，所以它天然是一个校验信号：

```
用量 = 上日库存 + 当日到货 − 当日库存
```

如果某天算出的**用量是负数**，说明三者至少有一个错：到货漏记、库存盘错、或日期串了。

**负数用量是最灵敏的漏记信号**——不需要额外做对账，看一眼就知道有问题。

## 六、周期性动作

| 频率 | 做什么 |
|---|---|
| **每天** | 填日报三个格，扫一眼提醒横幅 |
| **每笔单据** | 登记后立刻看校验区是否为 0 |
| **每周** | 查在途合同的到货进度、长期零到货合同 |
| **每月** | 对账：台账 vs 发票 vs 付款；查重复；查名称多种写法 |
| **每季/每年** | 存量合同清理、参数复核（提前期/日耗是否还准） |

## 七、对账自检清单

- [ ] 校验区三项"未挂合同"指标均为 **0**
- [ ] 校验区分解项之和自洽（已挂 + 未挂 = 总额）
- [ ] 无负数用量（或已查明原因）
- [ ] 疑似重复已标注，未自动删除
- [ ] 在途合同无长期零到货
- [ ] 供应商名称无多种写法并存
- [ ] 到货记录与合同跟踪的合同号可完全对上
- [ ] 发现的问题已逐条记录处置方式（便于复盘）
