# 05 · 自动化设计原则与避坑

台账做得好不好，看的不是列有多少，而是**"手工要填几个格"**。

## 一、第一原则：让表自己算

**判断一个台账设计好不好，就看一个数：每天/每笔必须手工填的字段有几个。**

- 好的设计：**日报只填 3 个格**（日期、库存、明日计划），其余全部自动
- 差的设计：20 列里 15 列要手填

**做法**：对每一个字段问一句——**"这个值能不能从别的字段推出来？"** 能推的，一律改成公式。

| 字段类型 | 处理 |
|---|---|
| 车数 | 自动：数几个车槽填了吨数 |
| 当日合计 | 自动：求和 |
| 累计、未到量、到货率 | 自动：按关联字段汇总 |
| 金额 | 自动：数量 × 单价 |
| 用量 | 自动：反推（见下） |
| 序号 | 自动：按行号生成，增删行自动重排 |
| 状态 | 自动：按阈值判断 |

**只保留三类必须手填的**：客观事实（日期、数量、金额）、外部信息（凭证号）、人的判断（备注）。

## 二、第二原则：让参数集中一处

安全库存、提前期、日耗、每车吨数这类"会变的数"，**全部放进一张参数表**，公式引用它。

- ✅ 改一个数，全表跟着变
- ⛔ 把参数写死在公式里（`库存/100`）—— 哪天日耗变了，要改几十处公式

## 三、第三原则：锚定"最新"，不要锚定"第几行"

看板类的指标（当前库存、最新到货、可用天数）**不要指向固定的某一行**。

**原因**：数据是每天往下插的，"最新"永远在变。钉死行号 → 明天就取错了。

**做法**：用公式找"最新的那一行"。

⚠️ **而且要按字段分开锚**：

| 要取的指标 | 锚在哪一行 |
|---|---|
| 最新日期 / 到货车数 / 到货量 | **最新填了日期的行** |
| 当前库存 / 可用天数 / 断料日 | **最新填了库存的行** |

**为什么分两套**：实际录入经常"记了日期忘了填库存"。用有日期的行去取库存 → 显示空白。

## 四、第四原则：下拉代替手打

供应商、合同编号、付款方式这类**从有限集合里选**的字段，挂**数据验证下拉**：

- 减少手打，自然消除错别字
- 保证跨表关联字段**完全一致**（这是汇总能对上的前提）

**两个细节**：

1. **下拉要允许手动输入**（否则遇到新供应商就填不进去）。下拉控件上有"输入无效数据时是否报错"的开关——**关掉它**。
2. **选项列表要能自动伸缩**（引用一整列而不是固定区域），否则新增合同要手工改下拉范围。

⚠️ 汇总公式如果按行首几个字做前缀匹配，**被匹配的那一列必须统一写简称**（全称写在旁边备注列）——否则"某某有限公司"和"某某"会被当成两家。

## 五、必须避开的坑

| 坑 | 后果 | 怎么做 |
|---|---|---|
| **求和范围包含合计行** | 数字翻倍 | 范围从**数据首行**起，不要从表头下第一行起 |
| 用"状态 ≠ 已结束"筛选汇总 | 合计行被命中 → 虚报 | 用专门的"在途未到量"列，别用状态筛 |
| 用新版才支持的函数 | 别人的办公软件打不开/算不出 | 用广泛支持的写法 |
| 用依赖排序的查找 | 换个排序全错 | 改成不依赖行序的写法 |
| 反推公式没判空 | 首行算出荒唐值 | 首行/找不到前一日时显示空白 |
| **重建表格后条件格式丢失** | 颜色标记没了（数据与公式仍在） | 属已知现象；重刷或接受 |
| 关联字段用了不同写法 | 汇总凭空少一块 | 下拉统一 + 校验区设"未挂项 = 0" |
| 公式里写死参数 | 参数变了要改几十处 | 集中到参数表 |
| 名称里嵌换行/空格 | 明明有也匹配不上 | 比较前先去空白 |

## 六、验收：每次改完表都要跑一遍

改公式、加列、重建表之后，**必须验证**，不能"看着差不多就用"。

**验证要读"算出来的值"，不能只看公式写对了没有**——有些工具打开文件时**不会计算公式**，读到的只是公式文本。

**必查项**：

- [ ] 关键汇总与手工核算的结果一致
- [ ] 校验区三项"未挂项"仍为 0
- [ ] 新加行的公式已下拉到底（不是只填了第一行）
- [ ] 下拉仍在生效，且允许手动输入
- [ ] 条件格式是否需要重刷
- [ ] 用同一份数据从空表重建一次，结果一致（可复现）

## 七、交付话术

- 先给结论数字，再给结构说明
- 明确写出**哪些格要手填、哪些自动** —— 这是使用者最需要知道的一件事
- 数据质量问题单独成表，说明"已标注未擅改"
- 写清原件未动、新文件位置

## 八、设计自检

- [ ] 手工必填字段已压到最少（日报 ≤3 格）
- [ ] 所有可推导字段都是公式
- [ ] 参数集中在参数表
- [ ] 看板指标锚定"最新行"，并按字段分两套锚
- [ ] 下拉已挂且允许手动输入，选项自动伸缩
- [ ] 汇总范围避开合计行
- [ ] 未使用新版专属函数、未使用依赖排序的查找
- [ ] 校验区"未挂项"为 0
- [ ] 改动后已读计算值验收
