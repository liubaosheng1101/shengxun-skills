## 二、采购明细：做成智能表

**必须做成 Table**，否则下游的透视表、切片器、结构化引用都用不了。

```python
from openpyxl.worksheet.table import Table, TableStyleInfo

tab = Table(displayName="采购台账", ref=f"A1:Z{LAST}")
tab.tableStyleInfo = TableStyleInfo(name="TableStyleLight9", showRowStripes=True)
ws.add_table(tab)
ws.freeze_panes = "C2"          # 冻结表头 + 前两列，横向滚动时仍能看到日期
```

- 表头在第 1 行、数据从第 2 行起（Table 的硬要求）。
- `displayName` 可用中文，但**不要含空格**。
- `freeze_panes = "C2"` 比 `"A2"` 好用得多——横滚时序号与日期始终可见。

**建议字段**（按实际增减）：序号 / 日期 / 年度 / 月份 / 季度 / 物料大类 / 物料类别 / 原始类别 / 物料名称 / 规格型号 / 单位 / 数量 / 含税单价 / 金额 / 未税单价 / 税率 / 供应商名称 / 厂家 / 品牌 / 联系人 / 联系电话 / 经办人 / 合同编号 / 来源月份 / 原始来源 / 数据备注

**年度、月份、季度用公式自维护**，不要写死值——日期被修正后能自动跟着变：

```
=IF($B2="","",YEAR($B2))
=IF($B2="","",MONTH($B2))
=IF($B2="","","Q"&ROUNDUP(MONTH($B2)/3,0))
```

「数据备注」列写异常标注（见 `06`），用户可直接按它筛选。

## 三、分析看板

建议七个板块：

1. 核心指标（总金额、总笔数、供应商数、覆盖期间）
2. 物料大类对比（本年度 / 跨年度）
3. 月度趋势
4. TOP20 供应商
5. TOP15 物料
6. 经办人统计
7. 数据质量校验（异常笔数与金额）

图表类型选择：

| 图 | 类型 | 用在 |
|---|---|---|
| 月度趋势 | `LineChart` | 看走势与拐点 |
| 大类占比 | `PieChart` | 看结构 |
| TOP 供应商 | `BarChart(type="bar")` | 横向条形，长名字不挤 |
| 跨年度大类对比 | `BarChart(type="col")` | 分组柱，看结构变化 |

图表插在数据区**右侧的空白列**，不要压住数据。

## 四、Excel 公式的几个坑

### ✅ 结构化引用可用

智能表的结构化引用在 openpyxl 里写得进去，Excel 打开也能算：

```
=SUM(采购台账[金额（元）])
=SUMIFS(采购台账[金额（元）],采购台账[年度],2025)
=COUNTIFS(采购台账[物料大类],"化工原料")
=COUNTIF(采购台账[数据备注],"*疑似重复*")
```

**列名含全角括号「（元）」不影响解析**——Excel 只对半角 `[ ] # ' @` 敏感。

### ❌ 数组型去重计数会返回错误值

`SUMPRODUCT(...COUNTIF(表[列],表[列])...)` 这类去重计数实测会返回错误值（`-2146826273`）。

**改用汇总表绕开**：

```
=COUNTIF('供应商汇总'!$D$2:$D$999,">0")     # 该年度有采购的供应商数
=COUNTA('供应商汇总'!$B$2:$B$999)           # 供应商总数
```

### ⚠️ 引用中文表名要加单引号

```
='供应商汇总'!B12
```

### ⚠️ 条件值里的通配符

`SUMIFS` / `COUNTIFS` 的条件值若含 `*` 或 `?`，会被当成通配符。**用物料名称、供应商名称这类自由文本做条件时要留意**，必要时用 `SUBSTITUTE` 转义。

### ⚠️ TOP N 不要用 LARGE + INDEX/MATCH

金额并列时 `LARGE` + `INDEX/MATCH` 会重复取到同一行。

**做法**：排序后直接引用前 N 行。

```
='供应商汇总'!A2      # 第 1 名
```
