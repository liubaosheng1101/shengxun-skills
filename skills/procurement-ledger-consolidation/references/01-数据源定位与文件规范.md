# 01 · 数据源定位与文件规范

## 一、先扫描，别凭记忆

台账的真实结构几乎总和记忆不同：有的年度是一个文件装 12 个月度工作表，有的是每月一个独立文件；有的表头在第 1 行，有的在第 2 行，还有的藏在第 17 行。**凭记忆写路径与表头行号，是这类任务第一个翻车点。**

开工第一步，跑一遍目录扫描，把这三件事确认下来：

1. **有哪几年、哪些文件**（总台账 / 月度台账 / 归档件）
2. **每个文件的表头在第几行**
3. **每个文件的覆盖范围到哪个月**

## 二、典型目录形态（依实际调整）

```
台账/
├── <年A>/采购台账/
│   ├── <单位><年A>年总台账.xlsx      ← 可能是「12 个月度 sheet + 1 个汇总 sheet」
│   └── 月度台账/<单位><年A>年N月台账.xlsx
└── <年B>/采购台账/
    ├── <单位><年B>年总台账.xlsx      ← 可能是「单 sheet 明细数据」，与年A结构不同
    └── 月度台账/<单位><年B>年N月台账.xlsx
```

⚠️ **同一年度的总台账与月度台账，结构常常不一样**（sheet 数、表头行、列序都可能不同）。**不要写一套解析逻辑套所有文件**，按文件类型分派。

## 三、归档命名铁律

归档件常带后缀标记。**后缀必须插在扩展名之前**：

| 正确 | 错误 |
|---|---|
| `xxx._archived.xlsx` | `xxx.xlsx._archived` |

写成右边那种，系统**认不出文件类型**——双击会弹「选择一个应用以打开 `._archived` 文件」，且推荐列表里没有 Excel（因为 `.xlsx` 不在末尾）。

**遇到错误命名时**：复制成正常扩展名的临时副本再读，并顺手把文件名改对。

```python
import shutil, os, tempfile
tmp = tempfile.mkdtemp()
shutil.copy2(src, os.path.join(tmp, "tmp.xlsx"))   # 再读这个副本
```

## 四、覆盖范围必须比对

⚠️ **「年度总台账」不一定含全年度数据。**

实测常态：某年的总台账只到 7 月，8 / 9 月的数据只在对应的月度台账里。

**做法**：先读总台账的月份覆盖范围，再与该年度应有月份比对，缺的从月度台账补读。**不比对就合并，会静默少几个月的数据。**

## 五、多来源冲突如何处理

同一笔数据可能同时出现在总台账和月度台账里，且**金额本身可能不一致**（源表之间的历史差异）。

处理原则：

1. **以数据行完整的表为准**（通常是逐月登记的月度表，或标记为年度汇总的那张）。
2. **差异如实告知用户**，列出差异月份与金额。
3. ⛔ **绝不擅自"调平"**。调平会掩盖真实的登记问题。

## 六、开工前的确认清单

- [ ] 已扫描目录，列出全部数据文件
- [ ] 每个文件的**表头行号**已确认（不要假设都是第 1 行）
- [ ] 每个文件的**覆盖月份**已确认，缺口已从月度表补齐
- [ ] 归档件的命名是否符合「后缀在扩展名之前」
- [ ] 已确认源表之间是否存在金额差异，以及以哪张为准
