# 07 · 月度与年度分析维度

## 一、月度分析：六个维度

只有一个月的数据时，按这六块出。

| 维度 | 汇总什么 | 回答什么问题 |
|---|---|---|
| **汇总概览** | 总记录数、总采购金额、合同/发票记录数与金额、供应商数、物料类别数、统计期间 | 这个月总体什么水平 |
| **物料类别分析** | 按类别的记录数、总金额、平均金额、最大/最小金额、涉及供应商数 | 钱花在哪类物料上 |
| **供应商分析** | 按供应商的记录数、总金额、平均金额、最大/最小金额、涉及类别数 | 依赖哪几家 |
| **日期趋势** | 按日期的记录数与金额 | 有没有异常集中的日子 |
| **经办人分析** | 按经办人的记录数、总金额、平均金额 | 工作量与集中度 |
| **原始数据** | 完整明细 | 可核查 |

## 二、必须汇报的关键指标

不要只给表格。**先给这几个数字**：

1. **总金额**
2. **合同 / 发票的记录占比与金额占比**（合规性视角）
3. **TOP5 供应商**
4. **TOP5 物料类别**

再给结构与明细。

## 三、年度分析与跨年对比

多年度数据时，在月度维度的基础上加：

| 维度 | 看什么 |
|---|---|
| **年度对比** | 各年度总金额、笔数、供应商数；同比变化 |
| **结构变化** | 各大类占比的年度位移——哪类在涨、哪类在降 |
| **供应商格局** | 头部集中度变化；新增 / 退出供应商 |
| **月度节律** | 全年 12 个月的走势，找规律与异常月 |

## 四、输出结构建议

| Sheet | 内容 |
|---|---|
| **汇总概览** | 核心指标一页看完 |
| **物料类别分析** | 按类别汇总 + TOP 图表 |
| **供应商分析** | 按供应商汇总 + TOP 图表 |
| **日期趋势** | 按日期/月汇总 + 折线图 |
| **经办人分析** | 按经办人汇总 |
| **原始数据** | 完整明细 |

图表嵌入在工作表内：类别 TOP、供应商 TOP、日期趋势各一张。

## 五、分析口径的几个约定

- **金额一律用含税金额**（或以实际入账口径为准），并在报告里**写明用的是哪个口径**——含税/未税混用是这类报告最常见的争议点。
- **平均金额 = 总金额 / 记录数**，不是笔均单价。要看单价水平请单独按「数量 × 单价」算。
- **「合同/发票」占比**要明确分子分母：是"有合同编号的记录数占比"，还是"金额占比"——两者差别很大，写清楚。
- **最大/最小金额**容易受单笔异常值影响，汇报时**同时给出中位数或去掉 TOP1 后的值**更稳。
- **同一供应商的多写法要先归一**（见 `04`），否则供应商排名和集中度全失真。

## 六、表达纪律

- **先结论后数据**：先给"这个月花了多少、集中在哪、有没有异常"，再给表格。
- **不说"建议进一步分析"这类空话**。要说"某类金额环比涨 X%，主要来自某几笔，建议查这几笔的采购依据"。
- **异常项要点名到行**：不要只说"存在异常"，要给出是哪一天、哪个供应商、哪笔金额。
- **不确定的要说清是口径问题还是数据问题**——这两种的处置方式完全不同。
