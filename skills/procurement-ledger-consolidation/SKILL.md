# 采购台账清洗、合并与分析

把「几年下来、格式各异、错别字遍地」的采购台账，做成一张可信、可筛选、可分析的统一表。

**这个技能的价值不在"合并"这个动作**，而在于：**知道数据会在哪里静默出错**——日期丢行、列位错配、分类分裂、同一家供应商被拆成 4 条记录。这些错误不报错，只会让金额对不上。

## 一、四类任务路由（内部判断，不让用户选菜单）

| 用户想要 | 主路由 | 核心产出 |
|---|---|---|
| 把多年度/多表台账合成一张 | **台账合并** | 单张智能表（Excel Table）+ 看板 + 供应商汇总 |
| 数据太乱，先清理 | **数据清洗** | 日期解析、表头映射、分类归一、名称归一 |
| 就一个月/一年做分析 | **台账分析** | 汇总概览 + 分类/供应商/趋势/经办人多维度 + 关键指标 |
| 数据对不上，要查问题 | **质量校验** | 问题清单 + 差异对账 + 处置建议 |

一次请求走一条主路由，最多带一条辅助。

## 二、低打扰原则

1. 先看用户已有的表和字段，**能先跑一版清洗就先跑**，不要先问一堆业务定义。
2. 缺信息按顺序补：已有数据 → 从表头推断 → 用可回退的默认值并标注假设 → 给两版方案 → 实在无法推进才提问。
3. 首轮最多问一个问题，且必须是「不回答就没法清洗」的。
4. 用户只给一个文件时，直接给一版清洗结果 + 问题清单，在其上迭代。

## 三、硬性口径（所有产出必须满足）

1. **先扫描目录确认数据源，别凭记忆。** 目录结构、文件名、表头行位置都可能与预期不同。
2. **用表头名映射，绝不硬编码列号。** 各表列序不同，硬编码必然错配。
3. **日期列有三种形态**：`datetime` / 字符串 / **Excel 序列号（整数）**。只判其中一种会**静默丢行**（实测丢过上百行），且金额对不上时极难察觉。
4. **归一化必须保留原始列。** 原始值、标准化值、统一值各一列 → 可追溯、可回退。
5. **疑似重复只标注，不自动去重。** 同日期同物料同金额可能是真实的多笔。**误删真实数据比留着重复更糟。**
6. **供应商名称只出清单，不自动合并。** 由业务确认后再批量替换。
7. **`openpyxl` 不计算公式。** 凡是要读公式结果做验收的，必须用 `win32com` 打开读**计算值**。
8. **源表之间数字不一致时，以数据完整的表为准，如实告知，绝不擅自"调平"。**
9. **数据质量问题单独成表**，说明"已标注未擅改"，等确认。
10. **归档改名时，`_archived` 必须插在扩展名之前**（`xxx._archived.xlsx`）。写成 `xxx.xlsx._archived` 会让系统认不出文件类型。

## 四、工作流程：五步走

1. **定位**：扫描目录，确认有哪几年、哪些表、表头在第几行、覆盖范围到哪个月。
2. **解析**：日期统一解析（三态）+ 表头名映射 + 跳过汇总行。
3. **归一**：分类体系归一（保留原始列）+ 供应商名称归一（出清单）。
4. **输出**：智能表 + 分析看板 + 供应商汇总 + 待规范清单。
5. **验收**：零丢弃、逐月对账、读计算值核对，问题清单单独交付。

## 五、产出分级

**轻量问答**（"这个日期怎么读不出来"）：对话内直接给判断 + 代码片段。

**完整交付**按以下顺序：

1. 对话内先给结论数字（合计金额、行数、供应商数、发现的问题数）
2. 统一后的 Excel（智能表 + 分析看板 + 供应商汇总 + 待规范清单）
3. **数据质量问题清单**（单独一份，逐条给处置建议）
4. 验收报告（零丢弃核对、逐月对账、差异说明）

## 六、表达与边界

- 全程中文，使用采购台账的实操语言（含税单价、未税单价、物料大类、经办人、智能表、切片器）。
- 不写「建议进一步核对」这类空话；每条问题必须给**具体是哪一行、哪个字段、建议怎么处置**。
- **本技能只做数据处理与分析支持**，不替你判断业务对错（如某笔采购是否合理），也不做财务审计结论。
- 涉及金额差异时，**只如实呈现，不擅自调平**。
- 不承诺分析结果可用于对外报告或审计用途。
- **运行环境**：解析、归一、合并、出表等核心流程只依赖 `openpyxl`，Windows / macOS / Linux 均可运行。唯一例外是**验收环节**——读取公式的**计算值**需要本机 Excel，Windows 上用 `win32com`；非 Windows 环境降级为「用 `openpyxl` 读工作簿中已缓存的值，并明确提示可能读到的是公式串」，或请用户另存为含计算值的版本后再验收，**不要静默跳过验收**。
