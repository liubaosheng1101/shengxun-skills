# 03 · 剧本转分镜规范

适用于：把剧本拆成分镜脚本与分镜表。**输出必须严格按本文件的列名，改名会导致下游工具读不到字段。**

## 一、分镜表列定义（12 列，顺序固定）

| 列 | 说明 | 生成要点 |
|---|---|---|
| 集数 | 第几集 | 与剧本文件一致 |
| 镜头号 | S01 / S02… | 集内顺序，两位数字 |
| 起始 | `0s` / `3s` | 相对整集时间轴，必须**从 0 连续累加** |
| 时长 | `3s` | 建议 2–6 秒；台词长则相应加长 |
| 视频素材 | 文件名 | 该镜的画面文件名（可带相对路径） |
| 图片素材 | 文件名 | 无视频时用静帧兜底 |
| 台词 | 文本 | 角色台词或旁白，直接作为字幕 |
| 角色 | 角色名 | 用于匹配配音；旁白写「旁白」 |
| 音色文件 | 文件名 | 留空则按「角色」从映射表取 |
| 转场 | 转场键 | 如 硬切 / 叠加 / 中心旋转 |
| BGM | BGM 键 | 如 BGM_悬疑 / BGM_紧张 |
| 备注 | 自由文本 | 景别 / 情绪 / 特殊要求 |

## 二、时间轴口径（最容易错）

- `起始 + 时长` 必须等于下一镜的 `起始`，**无缝、无重叠**。
- 台词变长 → **加时长、不改起始**，其后所有镜头起始顺延重算。
- 校验方法：把 `起始` 逐行累加与总时长对账；对不上就是有一镜没接上。

## 三、转场与 BGM 的标注

- 转场只标有意义的：情绪断裂处用「硬切」，时空延续用「叠加」。**连续镜头默认不加转场**，不要每镜都标。
- BGM 按情绪给（紧张 / 悬疑 / 燃 / 悲 / 日常），同一情绪段保持一致，**不要一镜一换**。

## 四、素材命名与占位

- 命名规则：`集数_镜号_简述`，避免中文空格与特殊符号。
- 素材还没生成时**先占位**，文件名写成最终会落盘的名字即可，生成后放到对应目录自动被找到。
- 静帧兜底：该镜没有视频素材时填图片素材，**不要留空两列**。

## 五、输出格式

- CSV，**UTF-8 with BOM**（否则 Excel 打开中文乱码），带表头。
- 一行一镜；不合并单元格；一镜不写多行台词（多行台词拆成多镜）。
- 首行示例：

```
集数,镜头号,起始,时长,视频素材,图片素材,台词,角色,音色文件,转场,BGM,备注
1,S01,0s,3s,,素材/开场.png,她当众把离婚协议撕了。,女主,,硬切,BGM_紧张,结果前置钩子
```

## 六、拆镜的操作顺序

1. 通读剧本，按场景切分段；
2. 每段再按**信息点**切镜头（一个信息点一镜）；
3. 台词按 ≤6 秒切开，分到相邻镜头；
4. 逐镜填 12 列：先填台词与角色 → 再补时间轴 → 最后补转场 / BGM；
5. 跑 `04-分镜自检与节奏.md` 的清单。

## 七、常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 列名被改写（如「起始时间」「镜头时长」） | 下游工具读不到字段 | 严格按 §一 原文列名 |
| 起始不连续（跳号、重叠） | 音画错位 | 逐行累加对账 |
| 一镜里塞多句台词 | 单镜过长、字幕超屏 | 拆镜 |
| 视频与图片素材都留空 | 该镜无画面 | 至少填一个 |
| 用「然后」这类小标题替代镜头 | 拆镜不落地 | 每个镜头必须有具体画面 |
