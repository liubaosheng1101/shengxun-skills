# 02 · 剧本结构与台词

适用于：写分集大纲、写逐场剧本、写台词、设计集尾结转。

## 一、单集节拍（以 60 秒为例）

| 段 | 时间 | 作用 | 镜头数参考 |
|---|---|---|---|
| 钩子 | 0–3s | 结果或冲突前置，抓人 | 1–2 |
| 铺垫 | 3–15s | 交代处境与关系，信息藏在动作里 | 3–5 |
| 冲突 | 15–40s | 矛盾升级，情绪推高 | 5–8 |
| 反转 | 40–52s | 给出本集的结算爽点 | 3–5 |
| 结转 | 52–60s | 抛下一集的钩子 | 2–3 |

时长不是 60 秒时按比例缩放，但**钩子与结转不能压缩**。

## 二、剧本格式（逐场）

```
【第 N 集 · 场景 X】
地点：（内景 / 外景 · 具体地点）
人物：A、B
时间：日 / 夜

【画面】一句画面描述（写「看到什么」，不写「感受」）
【动作】人物的关键动作
【台词】
A：（情绪）台词内容。
B：（情绪）台词内容。
```

写法纪律：

- 【画面】只写镜头能看到的东西。写「她心凉了」没用，要写「她手停在半空，眼睛没眨」。
- 情绪标注写**可表演的状态**（压着的怒、装作镇定、突然发紧），不写抽象词。

## 三、台词纪律

1. **一句一个信息**——一句话塞两个矛盾，观众记不住。
2. **不念设定**——「我是三年前被赶出家门的女儿」这种句子，改成让对手说出来，或用画面交代。
3. **口语化**——书面语（「此举」「届时」「颇为」）一律改口语。
4. **留话头**——对话要有攻防，不要一问一答都答满，留一半让对方怼回来。
5. **长度控制**——单句台词念出来 **≤6 秒**；超了就拆成两句、分到两个镜头。

## 四、人物功能四件套

写任何一集，先确认这四种功能都有人承担：

| 功能 | 作用 | 缺失后果 |
|---|---|---|
| 主角 | 承载观众代入 | 无 |
| 对手 | 制造压力 | 没有冲突，节奏塌 |
| 帮手 | 提供信息或反转助力 | 主角孤军，反转不自然 |
| 工具人 | 传递信息、被牺牲 | 信息只能靠旁白硬讲 |

## 五、集尾结转（每一集都要有）

结转 = 在结算本集爽点之后，抛出一个**新的、更难的**问题或威胁。三种做法：

1. **新角色入场**——一个还没解释的人出现；
2. **旧信息翻案**——「她以为自己赢了，直到看到那张照片」；
3. **威胁升级**——对手换了更大的牌。

结转的最后一句台词应**短**（≤12 字），并配一个可留白的画面。

## 六、自检

- [ ] 五段节拍齐全，钩子与结转都在
- [ ] 每场都有可看的信息（不是只有对话）
- [ ] 台词全部口语化、单句 ≤6 秒
- [ ] 没有旁白念设定
- [ ] 四类人物功能齐全
- [ ] 集尾有明确的结转钩子
