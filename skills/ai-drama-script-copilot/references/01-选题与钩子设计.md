# 01 · 选题与钩子设计

适用于：定题材、写开场、判断「这开头能不能留住人」。

## 一、什么样的题材在短视频平台吃得开

判断一个题材能不能做，看四条：

1. **一句话能说清冲突**——说不清的题材，前三秒也留不住人。
2. **情绪是「爽 / 怕 / 气 / 爽回来」之一**——平淡叙事不吃量。
3. **主角有身份落差或秘密**——马甲、隐藏身份、被低估，是持续钩子的来源。
4. **每集能独立给一个小结果**——短剧不是长剧，一集必须有一个可结算的爽点。

高频可用母题：伪玄学悬疑、身份反转、打脸逆袭、复仇、契约关系、夺产、伪装身份。

## 二、前三秒钩子的四种基本型

| 型 | 做法 | 写法示意 |
|---|---|---|
| 结果前置 | 先把最炸的结果甩出来，再倒叙 | 开场即「她当众把离婚协议撕了」 |
| 冲突前置 | 直接进入冲突现场，不给铺垫 | 两人已在争吵对峙，观众从半句台词进场 |
| 悬念提问 | 抛一个必须知道答案的问题 | 「这张照片上的人，三年前就死了」 |
| 身份反差 | 亮出与处境不匹配的身份 | 被赶出门的保洁，接了通电话叫「董事长」 |

选型规则：**优先结果前置与冲突前置**（不依赖观众耐心）；悬念提问适合悬疑向；身份反差适合马甲向。

## 三、前三秒分镜怎么落（写进分镜表 S01）

S01 必须同时满足：

- 时长 **2–3 秒**，不超过 3 秒；
- 有**人**（不能是空镜、风景、字幕板）；
- 有**动作或对峙**（不能是静态人物站着说话）；
- 台词**不超过 12 个字**（也可用画面+音效，但必须有信息）；
- 画面里**不出现人物介绍字幕**。

写法示例：

```
1,S01,0s,3s,,素材/开场.png,她当众把离婚协议撕了。,女主,,硬切,BGM_紧张,结果前置钩子
```

## 四、无效开场黑名单（见到就删）

| 无效开场 | 为什么失效 |
|---|---|
| 环境空镜、城市航拍、天气铺垫 | 观众不知道要看什么，直接划走 |
| 字幕 / 旁白先介绍人物背景 | 短视频没有「等我讲完」的耐心 |
| 上一集回顾、总集提要 | 只对已追的人有用，对新人等于零 |
| 慢摇、无意义推拉、人物背影 | 没有信息量 |
| 一大段旁白念设定（世界观、家族关系） | 信息密度低，且「讲」不如「演」 |

## 五、钩子自检（逐条打勾）

- [ ] S01 在 0–3 秒内，且有人物、有动作
- [ ] 3 秒内能看出「这里出事了」
- [ ] 前 10 秒内出现了本集主要矛盾的对象（人或事）
- [ ] 开场台词 ≤12 字，且不是自我介绍
- [ ] 没有旁白念背景设定

任一条不通过 → 回到 §三 重写 S01，**不要靠后面剪辑补救**。
