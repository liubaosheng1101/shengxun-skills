# 05 · 发布前合规自检

适用于：片子做完、准备发布前的风险预检。

⚠️ 本文件只是**事前风险提示**，不构成法律意见，也不代表平台审核结论。最终以平台判定为准。

## 一、AIGC 标识（硬要求）

- AI 生成内容必须标识，**放在前 5 秒内**，持续 **≥3 秒**，居中不遮挡主体。
- 文案示例：`本视频由 AI 生成`。
- 不要把标识塞进片尾或用极小字号——不满足「显著」要求。

## 二、标题与封面文案红线

| 禁止 | 原因 |
|---|---|
| 「热播」「强推」「最」「第一」「国家级」 | 极限词 / 虚假宣传 |
| 「不转不是中国人」「点击领钱」 | 诱导 / 违规导流 |
| 医疗、金融、投资类效果承诺 | 需资质，个人号不能发 |
| 用真人明星姓名 / 肖像暗示 | 侵权 |
| 血腥、肢体伤害画面的封面帧 | 内容风险 |

封面帧选择：选**人物表情清晰、无冲突动作**的一帧，人物眼睛在画面上部 1/3。

## 三、内容风险预检（逐条过）

- [ ] 无血腥、肢体伤害、自残细节
- [ ] 无危险动作可模仿示范（如开车斗气、玩火）
- [ ] 无宗教 / 迷信的「实际效果」承诺（伪玄学题材务必架空化，不指向现实可操作行为）
- [ ] 无未成年人处于危险或不良情境
- [ ] 无对现实群体、职业的地域或身份歧视
- [ ] 无真人可识别面孔（AI 生成人物不应与真实公众人物相似）
- [ ] 无未授权商标、品牌标识入镜

## 四、常见驳回原因对照

| 驳回提示关键词 | 通常对应问题 | 处理方向 |
|---|---|---|
| 低质 / 搬运 | 画面重复、静止帧过多、无信息增量 | 提高镜头切换率、补信息点 |
| 涉及不良价值观 | 复仇 / 暴力被展示为可推崇 | 改为「代价」叙事，弱化手段展示 |
| 疑似真人 | 人像与真人高度相似 | 换参考风格或重做该镜 |
| 未标注 AI 生成 | 缺 AIGC 标识 | 前 5 秒补标识 |
| 含违禁词 | 标题 / 字幕出现极限词 | 改标题，检字幕 |

## 五、字幕与音频

- 字幕单行、不叠字、底部安全区留 **≥12%**；
- 无静音段；响度目标 **−14 LUFS**（LRA ≤12）；
- 无侵权音乐（用自制或授权 BGM）。
