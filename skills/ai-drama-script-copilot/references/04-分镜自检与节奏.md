# 04 · 分镜自检与节奏

适用于：分镜写完后的质量检查与修改。

## 一、硬指标（不通过就必须改）

- [ ] S01 在 0–3 秒且有人物、有动作（见 `01-选题与钩子设计.md`）
- [ ] 时间轴无缝：每镜 `起始 + 时长` = 下一镜 `起始`
- [ ] 单镜在 2–6 秒；**平均 ≤4.5 秒**
- [ ] 台词密度 ≤6 秒/次（无台词画面连续不超过 6 秒）
- [ ] 每镜至少有一个素材（视频或图片），无空镜
- [ ] 集尾有结转镜头
- [ ] 画幅与目标平台一致（竖屏 9:16 为主）
- [ ] 无旁白念设定段落

## 二、常见节奏病与改法

| 病症 | 表现 | 改法 |
|---|---|---|
| 长镜拖沓 | 单镜 >6 秒 | 一镜拆两镜，或压缩台词 |
| 台词堆叠 | 一镜里换人多、信息量大 | 一镜一信息，拆开 |
| 连续空镜 | 连续两镜以上没人 | 至少一镜换成有人物的反应镜 |
| 情绪断层 | 上一镜很紧，下一镜突然日常 | 中间补一个过渡反应镜 |
| 钩子后置 | 冲突到第 8 秒才出现 | 把冲突素材剪切到 S01 |
| 结尾无力 | 结算完直接结束 | 补一个 2 秒结转镜 |

## 三、镜头数与时长的对照（按目标时长缩放）

| 目标时长 | 镜头数参考 | 平均镜长 |
|---|---|---|
| 30s | 8–10 | ≤3.5s |
| 60s | 15–20 | ≤4.5s |
| 90s | 22–30 | ≤4.5s |
| 120s | 30–40 | ≤4.5s |

## 四、自检结果的呈现方式

按下述格式输出，**每条都给具体改法**，不写「建议优化」：

```
【硬指标】
通过：时间轴、单镜时长、素材完整性
不通过：
· 平均镜长 5.6s（标准 ≤4.5s）→ S07/S11/S18 三镜超长，
  建议 S07 拆为 2 镜（台词拆句）
· 台词密度：S14–S16 连续 9 秒无台词 → S15 补一句主角反应台词
· 集尾结转缺失 → 在 S20 后补一镜（2s，对手接到电话）
```
